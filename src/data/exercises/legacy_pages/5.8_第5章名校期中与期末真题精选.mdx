## 三、计算与证明综合真题精解

<Exercise title="真题 1 · [分析下期中] 2024–2025 综合 (10分)">
设 $z = f(x+y) + g(e^x, xy)$，其中 $f$ 二阶可导，$g$ 有二阶连续偏导数，求 $\frac{\partial^2 z}{\partial x \partial y}$。

<Solution title="查看参考答案与提示">
**【参考答案】** $\frac{\partial^2 z}{\partial x \partial y} = f''(x+y) + xe^x g_{12}(e^x, xy) + xyg_{22}(e^x, xy) + g_2(e^x, xy)$

> **考察考点**：偏导数、连续偏导、\partial（对应小节：`5.3_多元数量值函数的导数与微分`）
</Solution>
</Exercise>

<Exercise title="真题 2 · [分析下期中] 2024–2025 综合 (10分)">
设 $z = z(x,y)$ 是由方程 $2x^2 - xy - y^2 + z + e^z = e$ 确定的隐函数，且 $z(0,1) = 1$，求 $\mathrm{d}z|_{(0,1)}$ 和 $\frac{\partial^2 z}{\partial x \partial y}|_{(0,1)}$。

<Solution title="查看参考答案与提示">
**【参考答案】** $\mathrm{d}z|_{(0,1)} = \frac{\mathrm{d}x + 2\mathrm{d}y}{1+e}$，$\frac{\partial^2 z}{\partial x \partial y}|_{(0,1)} = \frac{1+e^2}{(1+e)^3}$

> **考察考点**：\partial（对应小节：`5.3_多元数量值函数的导数与微分`）
</Solution>
</Exercise>

<Exercise title="真题 3 · [分析下期中] 2024–2025 A卷 (10分)">
设 $z = z(x,y)$ 是由方程 $F\left(z + \frac{1}{x}, z - \frac{1}{y}\right) = 0$ 确定的隐函数，且具有连续的二阶偏导数. 求 $x^2 \frac{\partial z}{\partial x} - y^2 \frac{\partial z}{\partial y}$ 和 $x^3 \frac{\partial^2 z}{\partial x^2} + xy(x-y)\frac{\partial^2 z}{\partial x \partial y} - y^3 \frac{\partial^2 z}{\partial y^2}$．

<Solution title="查看参考答案与提示">
**【参考答案】** $x^2 \frac{\partial z}{\partial x} - y^2 \frac{\partial z}{\partial y} = 1$，$x^3 \frac{\partial^2 z}{\partial x^2} + xy(x-y)\frac{\partial^2 z}{\partial x \partial y} - y^3 \frac{\partial^2 z}{\partial y^2} = -2$

> **考察考点**：偏导数、\partial（对应小节：`5.3_多元数量值函数的导数与微分`）
</Solution>
</Exercise>
