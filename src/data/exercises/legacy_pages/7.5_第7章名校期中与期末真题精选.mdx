## 二、填空题真题精解

<Exercise title="真题 1 · [分析下期中] 2022–2023 综合 (5分)">
幂级数 $\sum_{n=1}^{\infty} \frac{n+1}{n!} x^n$ 的和函数为 $S(x) = \underline{\quad\quad}$

<Solution title="查看参考答案与提示">
**【参考答案】** $(x+1)e^x - 1, -\infty < x < \infty$

> **考察考点**：幂级数、和函数（对应小节：`7.3_幂级数`）
</Solution>
</Exercise>

<Exercise title="真题 2 · [分析下期中] 2022–2023 综合 (5分)">
函数 $f(x) = \begin{cases} 0, & 0 \le x \le \frac{1}{2} \\ x+1, & \frac{1}{2} < x \le 1 \end{cases}$，将其展开正弦级数 $\sum_{n=1}^{\infty} b_n \sin n\pi x$，其中 $b_n = 2 \int_{0}^{1} f(x) \sin n\pi x \, \mathrm{d}x$，和函数为 $s(x)$，则 $s(-\frac{3}{4}) = \underline{\quad\quad}$

<Solution title="查看参考答案与提示">
**【参考答案】** $\frac{3}{4}$

> **考察考点**：和函数（对应小节：`7.2_函数项级数`）
</Solution>
</Exercise>

<Exercise title="真题 3 · [分析下期中] 2022–2023 A卷 (5分)">
已知级数 $\sum_{n=1}^{\infty} \frac{(-1)^{n-1}}{n^p + (-1)^{n-1}}$ 条件收敛，则常数 $p$ 的取值范围是 $\underline{\quad\quad}$。

<Solution title="查看参考答案与提示">
**【参考答案】** $\frac{1}{2} < p \le 1$

> **考察考点**：条件收敛（对应小节：`7.1_常数项级数`）
</Solution>
</Exercise>

<Exercise title="真题 4 · [分析下期中] 2022–2023 A卷 (5分)">
函数 $f(x) = \frac{1}{x^2+2x-3}$ 展开为 $x+1$ 的幂级数 $\underline{\quad\quad}$。

<Solution title="查看参考答案与提示">
**【参考答案】** $\sum_{n=0}^{\infty} \left(-\frac{1}{2^{2n+2}}\right)(x+1)^{2n}, -3 < x < 1$ 或 $\sum_{n=0}^{\infty} \frac{(-1)^{n-1}}{2^{n+3}}(x+1)^n, -3 < x < 1$

> **考察考点**：幂级数（对应小节：`7.3_幂级数`）
</Solution>
</Exercise>

## 三、计算与证明综合真题精解

<Exercise title="真题 1 · [分析下期中] 2023–2024 A卷 (15分)">
求幂级数 $\sum_{n=1}^{\infty} \frac{1}{2n-1}(x-1)^{2n-1}$ 的收敛域及函数. 并求 $\sum_{n=1}^{\infty} \frac{1}{(2n-1)2^n}$ 的和.

<Solution title="查看参考答案与提示">
**【参考答案】** 收敛域为 $(0, 2)$，和函数 $s(x) = \frac{1}{2} \ln \frac{x}{2-x}$，级数的和为 $\frac{\sqrt{2}}{2} \ln(\sqrt{2}+1)$

> **考察考点**：幂级数、和函数（对应小节：`7.3_幂级数`）
</Solution>
</Exercise>

<Solution title="查看参考答案与提示">
**【参考答案】** 收敛半径 $R=3$，收敛域 $(-3, 3)$

</Solution>
</Exercise>

<Exercise title="真题 3 · [分析下期中] 2022–2023 综合 (15分)">

<Solution title="查看参考答案与提示">
**【参考答案】** $f(x) = \sum_{n=0}^{\infty} \frac{(-1)^n + 2^{n+1}}{3} x^n, -\frac{1}{2} < x < \frac{1}{2}$

> **考察考点**：幂级数（对应小节：`7.3_幂级数`）
</Solution>
</Exercise>

<Exercise title="真题 4 · [分析下期中] 2022–2023 A卷 (10分)">

**【参考答案】** $s(x) = \begin{cases} \frac{x \sin x + \cos x - 1}{x^2}, & x \neq 0 \\ \frac{1}{2}, & x = 0 \end{cases}$
