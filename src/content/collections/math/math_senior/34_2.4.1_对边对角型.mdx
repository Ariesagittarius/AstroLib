在三角形中, 若知道任意一边与该边所对角的大小, 我们就可以利用正弦定理结合三角函数来求最值, 或者利用余弦定理结合均值不等式来求最值.

<Example title="例 2.22">

(2020 全国Ⅱ理 17)△ABC 中, $\sin^{2}A - \sin^{2}B - \sin^{2}C = \sin B \sin C$ .

(I) 求 $A$ ;

(Ⅱ) 若 $BC = 3$ , 求 $\triangle ABC$ 周长的最大值.

<Analysis>
本例 (Ⅱ) 给出了 $BC = 3$ ，第 (I) 问我们可以求出 $-A$ ，这是典型的对边对角型，最常规的思路就是正弦定理与三角函数结合求最值.
</Analysis>

<Solution title="解析1">
 (I) 由正弦定理及题设得 $BC^{2} - AC^{2} - AB^{2} = AC \cdot AB$ . 再由余弦定理得

$$
\cos A = \frac {A C ^ {2} + A B ^ {2} - B C ^ {2}}{2 A C \cdot A B} = - \frac {A C \cdot A B}{2 A C \cdot A B} = - \frac {1}{2}.
$$

因为 $0 < A < \pi$ , 所以 $A = \frac{2\pi}{3}$ .

(Ⅱ) 由正弦定理及 (I) 得 $\frac{AC}{\sin B} = \frac{AB}{\sin C} = \frac{BC}{\sin A} = 2\sqrt{3}$ , 从而

$$
A C = 2 \sqrt {3} \sin B, \quad A B = 2 \sqrt {3} \sin C = 2 \sqrt {3} \sin (A + B) = 3 \cos B - \sqrt {3} \sin B
$$

$$
B C = 2 \sqrt {3} \sin A = 3.
$$

于是

$$
B C + A C + A B = 3 + \sqrt {3} \sin B + 3 \cos B = 3 + 2 \sqrt {3} \sin \left(B + \frac {\pi}{3}\right).
$$

又因为 $0 < B < \frac{\pi}{3}$ , 所以 $\frac{\pi}{3} < B + \frac{\pi}{3} < \frac{2\pi}{3}$ , 当且仅当 $B + \frac{\pi}{3} = \frac{\pi}{2}$ , 即 $B = \frac{\pi}{6}$ 时, $\triangle ABC$ 周长取得最大值 $3 + 2\sqrt{3}$ .
</Solution>

当然本例除了解析 1 还有更加便捷的思路. 那就是余弦定理, 为何这么说呢? 我们来看余弦定理: $a^2 = b^2 + c^2 - 2bc\cos A$ , 这个等式可以变形为

$$
a ^ {2} = (b + c) ^ {2} - 2 b c (1 + \cos A).
$$

在已知 $a$ 与 $A$ 的前提下, 很容易知道可以借助均值不等式求 $b + c$ 与 $bc$ 的最值, 其实也就是三角形的周长与面积的最值问题.

<Solution title="解析2">
 (I)同解析1.

(Ⅱ) 令 $BC = a, AB = c, AC = b$ . 由 $a = 3, A = \frac{2\pi}{3}$ , 结合余弦定理得

$$
a ^ {2} = b ^ {2} + c ^ {2} - 2 b c \cos {\frac {2 \pi}{3}} \Rightarrow (b + c) ^ {2} - 9 = b c.
$$

由均值不等式可得 $(b + c)^2 - 9 = bc \leqslant \left(\frac{b + c}{2}\right)^2$ ，解得 $b + c \leqslant 2\sqrt{3}$ ，当且仅当 $b = c = \sqrt{3}$ 时周长取得最大值， $\triangle ABC$ 周长的最大值为 $3 + 2\sqrt{3}$ .
</Solution>

</Example>

对比例2.22的两种解析, 可以得出这么一个结论, 解析 2 比解析 1 更加简洁. 那么解析 2 是不是更适合这类题型呢? 事实并非如此, 我们更加青睐解析 1, 为何这么说呢? 先看例题:

<Example title="例 2.23">

(2023 广东统考) 已知锐角 $\triangle ABC$ 内角 A, B, C 所对的边分别为 a, b, c, 且 $\cos 2A - \sqrt{3} \sin A + 2 = 0$ .

(I) 求 $A$ ;

(Ⅱ) 若 $a = 2\sqrt{3}$ , 求 $\triangle ABC$ 面积的取值范围.

<Solution>
 (I) 因为 $\cos 2A - \sqrt{3}\sin A + 2 = 0$ , 又因为 $\cos 2A = 1 - 2\sin^2 A$ , 所以 $2\sin^2 A + \sqrt{3}\sin A - 3 = 0$ , 即 $(2\sin A - \sqrt{3})(\sin A + \sqrt{3}) = 0$ , 解得 $\sin A = -\sqrt{3}$ (舍去) 或 $\sin A = \frac{\sqrt{3}}{2}$ , 又因为 $\triangle ABC$ 是锐角三角形, 所以 $A = \frac{\pi}{3}$ .
</Solution>

第 (II) 问是对边对角型, 因此, 正弦定理结合三角函数是常规解法.

<Solution title="解析 1">
 由正弦定理得 $\frac{b}{\sin B} = \frac{c}{\sin C} = \frac{a}{\sin A} = 4,$ 所以 $b = 4\sin B, c = 4\sin C.$ 又因为 $B + C = \frac{2\pi}{3},$ 所以 $c = 4\sin\left(\frac{2\pi}{3} - B\right).$ 设 $\triangle ABC$ 的面积 S, 则

$$
\begin{array}{r l} & {S = \frac {1}{2} b c \sin A = 4 \sqrt {3} \sin B \sin \left(\frac {2 \pi}{3} - B\right) = 4 \sqrt {3} \sin B \left(\frac {\sqrt {3}}{2} \cos B + \frac {1}{2} \sin B\right)} \\ & {\qquad = 6 \sin B \cos B + 2 \sqrt {3} \sin^ {2} B = 3 \sin 2 B - \sqrt {3} \cos 2 B + \sqrt {3}} \end{array}
$$

$$
= 2 \sqrt {3} \sin \left(2 B - \frac {\pi}{6}\right) + \sqrt {3}.
$$

因为 $\triangle ABC$ 是锐角三角形, 所以 $\left\{ \begin{array}{l} 0 < B < \frac{\pi}{2} \\ 0 < \frac{2\pi}{3} - B < \frac{\pi}{2} \end{array} \right.$ , 可得 $\frac{\pi}{6} < B < \frac{\pi}{2}$ , 则 $\frac{\pi}{6} < 2B - \frac{\pi}{6} < \frac{5\pi}{6}$ , 所以 $\sin (2B - \frac{\pi}{6}) \in \left(\frac{1}{2}, 1\right]$ , 从而 $2\sqrt{3} < S \leqslant 3\sqrt{3}$ , 故 $\triangle ABC$ 面积的取值范围为 $(2\sqrt{3}, 3\sqrt{3}]$ .
</Solution>

类比例2.22的解析 2, 我们利用余弦定理结合均值不等式来求解:

<Solution title="解析 2">
 由余弦定理可得 $a^2 = b^2 + c^2 - 2bc\cos A$ ，整理得

$$
1 2 = b ^ {2} + c ^ {2} - b c.\tag{2.4.1}
$$

$\triangle ABC$ 的面积为 $S = \frac{1}{2} bc\sin A = \frac{\sqrt{3}}{4} bc,$ 因此需要求出 $bc$ 的取值范围. 由式(2.4.1)可得

$$
1 2 + b c = b ^ {2} + c ^ {2} \geqslant 2 b c \Rightarrow b c \leqslant 1 2,
$$

当且仅当 $b = c$ 时等号成立. 此时 $bc \leqslant 12$ , 所以 $S \leqslant 3\sqrt{3}$ .
</Solution>

此时也许很多同学们发现问题了, 利用解析 2 中的方法, 我们只能求出面积的最大值, 面积的下限无法直接求出. 然而, 无法求出面积的下限并不代表将条件都转成边就一定不行, 我们再看解析 3.

<Solution title="解析 3">
 由余弦定理可得 $a^2 = b^2 + c^2 - bc$ ，又因为 $\triangle ABC$ 是锐角三角形，所以

$$
\left\{ \begin{array}{l} a ^ {2} + b ^ {2} - c ^ {2} > 0 \\ a ^ {2} + c ^ {2} - b ^ {2} > 0 \end{array} \right. \Rightarrow \left\{ \begin{array}{l} b ^ {2} + c ^ {2} - b c + b ^ {2} - c ^ {2} > 0 \\ b ^ {2} + c ^ {2} - b c + c ^ {2} - b ^ {2} > 0 \end{array} \right. \Rightarrow \frac {1}{2} <   \frac {c}{b} <   2.
$$

又因为 $a = 2\sqrt{3}$ , 所以 $b^{2} + c^{2} - bc = 12$ , 于是

$$
b c = \frac {1 2 b c}{b ^ {2} + c ^ {2} - b c} = \frac {1 2}{\frac {b}{c} + \frac {c}{b} - 1}.
$$

令 $x = \frac{c}{b}, f(x) = x + \frac{1}{x}, x \in \left(\frac{1}{2}, 2\right)$ , 利用对勾函数的性质得 $2 \leqslant f(x) < \frac{5}{2}$ , 则

$$
2 \leqslant \frac {c}{b} + \frac {b}{c} <   \frac {5}{2} \Rightarrow 8 <   \frac {1 2}{\frac {b}{c} + \frac {c}{b} - 1} \leqslant 1 2,
$$

即 $8 < bc \leqslant 12$ , 所以 $2\sqrt{3} < S \leqslant 3\sqrt{3}$ .
</Solution>

比较 3 种解法, 解析 3 我们不容易想到, 解析 2 只能求出最大值, 而解析 1 看似复杂, 但更加具有一般性.

</Example>

对于对边对角型的三角形最值问题, 我们可以得出以下经验总结:

<Block title="经验总结 2.2">
不论三角形有没有形状限制, 正弦定理结合三角函数求范围更具一般性.
</Block>

例2.22与例2.23是“对角对边型”求最值, 如果给的是“一角一邻边”, 那么求最值时略有不同, 但是核心思想不变, 要么统一成角, 要么统一成边, 请看下面例题.

<Example title="例 2.24">

(2019 全国Ⅲ理 18) $\triangle ABC$ 的内角 A, B, C 的对边分别是 a, b, c, 已知 $a \sin \frac{A + C}{2} = b \sin A$ .

(I) 求 $B$ ;

(Ⅱ) 若 $\triangle ABC$ 为锐角三角形, 且 $c = 1$ , 求 $\triangle ABC$ 面积的取值范围.

<Solution title="解析 1">
 (I) 由 $a \sin \frac{A + C}{2} = b \sin A$ 得 $\sin A \sin \left( \frac{\pi - B}{2} \right) = \sin B \sin A,$ 化简可得 $\cos \frac{B}{2} = \sin B = 2 \sin \frac{B}{2} \cos \frac{B}{2}.$ 因为 $B \in (0, \pi)$ ，所以 $\frac{B}{2} \in \left(0, \frac{\pi}{2}\right)$ ，因此 $\cos \frac{B}{2} \neq 0,$ 故 $\sin \frac{B}{2} = \frac{1}{2},$ 从而 $\frac{B}{2} = \frac{\pi}{6},$ 所以 $B = \frac{\pi}{3}.$

(Ⅱ) 首先 $S_{\triangle ABC} = \frac{1}{2} ac\sin B = \frac{\sqrt{3}}{4} a,$ 然后由正弦定理 $\frac{a}{\sin A} = \frac{c}{\sin C}$ 得 $a = \frac{\sin A}{\sin C}$ , 则

$$
S _ {\triangle A B C} = \frac {\sqrt {3}}{4} \times \frac {\sin A}{\sin C} = \frac {\sqrt {3}}{4} \times \frac {\sin \left(C + \frac {\pi}{3}\right)}{\sin C} = \frac {\sqrt {3}}{4} \times \frac {\frac {\sqrt {3}}{2} \cos C + \frac {1}{2} \sin C}{\sin C} = \frac {3}{8 \tan C} + \frac {\sqrt {3}}{8}.
$$

因为 $A = \pi - B - C = \frac{2\pi}{3} - C, \triangle ABC$ 是锐角三角形, 所以 $\left\{ \begin{array}{l} 0 < C < \frac{\pi}{2} \\ 0 < \frac{2\pi}{3} - C < \frac{\pi}{2} \end{array} \right.$ , 解得 $\frac{\pi}{6} < C < \frac{\pi}{2}$ , 所以 $\tan C \in \left(\frac{\sqrt{3}}{3}, +\infty\right)$ , 从而 $S_{\triangle ABC} \in \left(\frac{\sqrt{3}}{8}, \frac{\sqrt{3}}{2}\right)$ . 故 $\triangle ABC$ 面积的取值范围为 $\left(\frac{\sqrt{3}}{8}, \frac{\sqrt{3}}{2}\right)$ .
</Solution>

解析 1 是利用正弦定理把边转化为角, 然后结合三角函数求出最值. 同样的, 我们可以通过边来求解吗? 当然可以, 具体见解析 2.

<Solution title="解析 2">
 (I) 同解析 1;

(Ⅱ) 由 (I) 及题设得 $S_{\triangle ABC} = \frac{1}{2} ac \sin B = \frac{\sqrt{3}}{4} a$ , 由余弦定理得 $b^2 = a^2 + c^2 - 2ac \cos 60^\circ$ . 又因为 $\triangle ABC$ 是锐角三角形, 所以

$$
\left\{ \begin{array}{l l} \cos A > 0 \\ \cos C > 0 \end{array} \right. \Rightarrow \left\{ \begin{array}{l l} b ^ {2} + c ^ {2} - a ^ {2} > 0 \\ b ^ {2} + a ^ {2} - c ^ {2} > 0 \end{array} \right. \Rightarrow \left\{ \begin{array}{l l} a ^ {2} + c ^ {2} - a c + c ^ {2} - a ^ {2} > 0 \\ a ^ {2} + c ^ {2} - a c + a ^ {2} - c ^ {2} > 0 \end{array} \right.
$$

整理得 $\left\{\begin{aligned}2-a&>0\\ 2a^{2}-a&>0\end{aligned}\right.$ ，解得 $\frac{1}{2}<a<2$ ，从而 $\frac{\sqrt{3}}{8}<\frac{\sqrt{3}}{4}a<\frac{\sqrt{3}}{2}$ .

故 $\triangle ABC$ 面积的取值范围为 $\left(\frac{\sqrt{3}}{8},\frac{\sqrt{3}}{2}\right)$ 
</Solution>

</Example>
