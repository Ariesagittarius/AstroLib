<Exercise title="Exercise 8.4">

Consider the_&#123; &#125;CLIQUE problem restricted to graphs in which every vertex has degree at most 3. Call this problem_&#123; &#125;CLIQUE-3.

</Exercise>

(a) Prove that_&#123; &#125;CLIQUE-3 is in NP.

(b) What is wrong with the following proof of NP-completeness for_&#123; &#125;CLIQUE-3?

We know that the_&#123; &#125;CLIQUE problem in general graphs is NP-complete, so it is enough to present a reduction from_&#123; &#125;CLIQUE-3 to_&#123; &#125;CLIQUE. Given a graph G with vertices of degree ≤3, and a parameter g, the reduction leaves the graph and the parameter unchanged: clearly the output of the reduction is a possible input for the_&#123; &#125;CLIQUE problem. Furthermore, the answer to both problems is identical. This proves the correctness of the reduction and, therefore, the NP-completeness of_&#123; &#125;CLIQUE-3.

(c) It is true that the_&#123; &#125;VERTEX COVER problem remains NP-complete even when restricted to

graphs in which every vertex has degree at most 3. Call this problem_&#123; &#125;VC-3. What is wrong with the following proof of NP-completeness for_&#123; &#125;CLIQUE-3? We present a reduction from_&#123; &#125;VC-3 to_&#123; &#125;CLIQUE-3. Given a graph G = (V, E) with node degrees bounded by 3, and a parameter b, we create an instance of_&#123; &#125;CLIQUE-3 by leaving the graph unchanged and switching the parameter to |V | −b. Now, a subset C ⊆V is a vertex cover in G if and only if the complementary set V −C is a clique in G. Therefore G has a vertex cover of size ≤b if and only if it has a clique of size ≥|V | −b. This proves the correctness of the reduction and, consequently, the NP-completeness of_&#123; &#125;CLIQUE-3.

(d) Describe an O(|V |^&#123;4&#125;) algorithm for_&#123; &#125;CLIQUE-3.

<Exercise title="Exercise 8.16">

We are feeling experimental and want to create a new dish. There are various ingredients we can choose from and we’d like to use as many of them as possible, but some ingredients don’t go well with others. If there are n possible ingredients (numbered 1 to n), we write down an n × n matrix giving the discord between any pair of ingredients. This discord is a real number between 0.0 and 1.0, where 0.0 means “they go together perfectly” and 1.0 means “they really don’t go together.” Here’s an example matrix when there are five possible ingredients.

</Exercise>

1 2 3 4 5

1

0.0 0.4 0.2 0.9 1.0

2

0.4 0.0 0.1 1.0 0.2

3

0.2 0.1 0.0 0.8 0.5

4

0.9 1.0 0.8 0.0 0.2

5

1.0 0.2 0.5 0.2 0.0

In this case, ingredients 2 and 3 go together pretty well whereas 1 and 5 clash badly. Notice that this matrix is necessarily symmetric; and that the diagonal entries are always 0.0. Any set of ingredients incurs a penalty which is the sum of all discord values between pairs of ingredients. For instance, the set of ingredients &#123;1, 3, 5&#125; incurs a penalty of 0.2 + 1.0 + 0.5 = 1.7. We want this penalty to be small.

E_&#123;XPERIMENTAL&#125; CUISINE Input: n, the number of ingredients to choose from; D, the n×n “discord” matrix; some number p ≥0 Output: The maximum number of ingredients we can choose with penalty ≤p.

<Exercise title="Exercise 8.21">

Sequencing by hybridization. One experimental procedure for identifying a new DNA sequence repeatedly probes it to determine which k-mers (substrings of length k) it contains. Based on these, the full sequence must then be reconstructed. Let’s now formulate this as a combinatorial problem. For any string x (the DNA sequence), let Γ(x) denote the multiset of all of its k-mers. In particular, Γ(x) contains exactly |x| −k + 1 elements. The reconstruction problem is now easy to state: given a multiset of k-length strings, find a string x such that Γ(x) is exactly this multiset.

</Exercise>

(a) Show that the reconstruction problem reduces to R_&#123;UDRATA&#125; PATH. (Hint: Construct a di-

rected graph with one node for each k-mer, and with an edge from a to b if the last k −1 characters of a match the first k −1 characters of b.)

(b) But in fact, there is much better news. Show that the same problem also reduces to E_&#123;ULER&#125;

PATH. (Hint: This time, use one directed edge for each k-mer.)

<Exercise title="Exercise 8.22">

In task scheduling, it is common to use a graph representation with a node for each task and a directed edge from task i to task j if i is a precondition for j. This directed graph depicts the precedence constraints in the scheduling problem. Clearly, a schedule is possible if and only if the graph is acyclic; if it isn’t, we’d like to identify the smallest number of constraints that must be dropped so as to make it acyclic. Given a directed graph G = (V, E), a subset E^&#123;′&#125; ⊆E is called a feedback arc set if the removal of edges E^&#123;′&#125; renders G acyclic.

</Exercise>

F_&#123;EEDBACK&#125; ARC SET (_&#123;FAS&#125;): Given a directed graph G = (V, E) and a budget b, find a feedback arc set of ≤b edges, if one exists.

(a) Show that_&#123; &#125;FAS is in NP.

F_&#123;AS&#125; can be shown to be NP-complete by a reduction from_&#123; &#125;VERTEX COVER. Given an instance (G, b) of_&#123; &#125;VERTEX COVER, where G is an undirected graph and we want a vertex cover of size ≤b, we construct a instance (G^&#123;′&#125;, b) of_&#123; &#125;FAS as follows. If G = (V, E) has n vertices v_&#123;1&#125;, . . . , v_&#123;n&#125;, then make G^&#123;′&#125; = (V^&#123; &#125;′, E^&#123;′&#125;) a directed graph with 2n vertices w_&#123;1&#125;, w^&#123;′&#125;

1, . . . , w_&#123;n&#125;, w^&#123;′&#125; n, and n + 2|E| (directed) edges:

• (w_&#123;i&#125;, w^&#123;′&#125; i) for all i = 1, 2, . . ., n.

• (w^&#123;′&#125; i, w_&#123;j&#125;) and (w^&#123;′&#125;

j, w_&#123;i&#125;) for every (v_&#123;i&#125;, v_&#123;j&#125;) ∈E.

(b) Show that if G contains a vertex cover of size b, then G^&#123;′&#125; contains a feedback arc set of size

b.

(c) Show that if G^&#123;′&#125; contains a feedback arc set of size b, then G contains a vertex cover of size

(at most) b. (Hint: given a feedback arc set of size b in G^&#123;′&#125;, you may need to first modify it slightly to obtain another one which is of a more convenient form, but is of the same size or smaller. Then, argue that G must contain a vertex cover of the same size as the modified feedback arc set.)

<Exercise title="Exercise 8.23">

In the_&#123; &#125;NODE-_&#123;DISJOINT&#125; PATHS problem, the input is an undirected graph in which some vertices have been specially marked: a certain number of “sources” s_&#123;1&#125;, s_&#123;2&#125;, . . . s_&#123;k&#125; and an equal number of “destinations” t_&#123;1&#125;, t_&#123;2&#125;, . . . t_&#123;k&#125;. The goal is to find k node-disjoint paths (that is, paths which have no nodes in common) where the ith path goes from s_&#123;i&#125; to t_&#123;i&#125;. Show that this problem is NP-complete. Here is a sequence of progressively stronger hints.

</Exercise>

(a) Reduce from 3_&#123;SAT&#125;.

(b) For a 3_&#123;SAT&#125; formula with m clauses and n variables, use k = m+n sources and destinations.

Introduce one source/destination pair (s_&#123;x&#125;, t_&#123;x&#125;) for each variable x, and one source/destination pair (s_&#123;c&#125;, t_&#123;c&#125;) for each clause c.

(c) For each 3_&#123;SAT&#125; clause, introduce 6 new intermediate vertices, one for each literal occurring

in that clause and one for its complement.

(d) Notice that if the path from s_&#123;c&#125; to t_&#123;c&#125; goes through some intermediate vertex representing,

say, an occurrence of variable x, then no other path can go through that vertex. What vertex would you like the other path to be forced to go through instead?
