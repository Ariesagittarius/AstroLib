## 10.2 计划

量子算法与您迄今为止看到的任何算法都不同。它的结构反映了 n 量子位系统的指数“私人工作空间”与通过测量可以获得的仅仅 n 位之间的紧张关系。

量子算法的输入由 n 个经典位组成，输出也由 n 个经典位组成。当量子系统没有受到关注时，量子效应就会发挥作用，我们受益于大自然为我们付出指数级的努力。

如果输入是 n 位字符串 x，则量子计算机将状态 x 中的 n 个量子位作为输入。然后执行一系列量子操作，最后 n 个量子位的状态已转换为某种叠加 $\textstyle \sum _ { y } \alpha _ { y } | y \rangle$ 。最后进行测量，输出是概率为 $| \alpha _ { y } | ^ { 2 } .$ 的 n 位字符串 y 。观察这个输出是随机的。但这不是问题，正如我们之前在随机算法（例如素性测试算法）中看到的那样。只要y以足够高的概率对应于正确答案，我们就可以重复整个过程几次，以使失败的机会变得很小。

现在让我们更仔细地看看该算法的量子部分。一些关键的量子运算（我们将很快讨论）可以被认为是在状态叠加中寻找某些类型的模式。因此，将算法视为具有两个阶段是有帮助的。在第一阶段，输入的 n 个经典位被“解包”成指数级大的叠加，该叠加被明确设置为具有潜在的模式或规律，如果检测到该模式或规律，将解决手头的任务。第二阶段由一组合适的量子操作组成，然后进行测量，揭示

隐藏的图案。
