## 4.3 边的长度

宽度优先搜索将所有边视为具有相同的长度。在需要找到最短路径的应用程序中，这种情况很少发生。例如，假设您从旧金山开车到拉斯维加斯，并且想要找到最快的路线。图 4.5 显示了您可能会使用的主要高速公路。选择它们的正确组合是一个最短路径问题，其中每条边（高速公路的每一段）的长度都很重要。在本章的剩余部分，我们将处理这个更一般的场景，用长度 $l _ { e } . \operatorname { I f } e = ( u , v )$ 注释每条边 $e \in E$ ，有时我们也会写 $l ( u , v ) \ \mathbf { o r } \ l _ { u v }$

这些 $l _ { e } \mathbf { \hat { s } }$ 不必对应于物理长度。它们可以表示时间（城市之间的驾驶时间）或金钱（乘坐公共汽车的成本），或我们想要节省的任何其他数量。事实上，在某些情况下我们需要使用负长度，但我们会暂时忽略这个特殊的复杂性。
