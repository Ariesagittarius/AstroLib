<Exercise title="Exercise 8.4">

考虑仅限于每个顶点度数最多为 3 的图的 CLIQUE 问题。将此问题称为 CLIQUE-3。

(a) 证明 CLIQUE-3 处于 NP 状态。

(b) 以下 CLIQUE-3 的 NP 完整性证明有什么问题？

我们知道一般图中的 CLIQUE 问题是 NP 完全的，因此只需提出从 CLIQUE-3 到 CLIQUE 的约简即可。给定一个具有 3 度顶点的图 G 和一个参数 g，归约使图和参数保持不变：显然，归约的输出是 CLIQUE 问题的可能输入。此外，两个问题的答案是相同的。这证明了约简的正确性，从而证明了 CLIQUE-3 的 NP 完整性。

(c) 确实，即使限制到每个顶点的度数最多为 3 的图，VERTEX COVER 问题仍然是 NP 完全问题。将此问题称为 VC-3。以下 CLIQUE-3 的 NP 完整性证明有什么问题？

我们提出了从 VC-3 到 CLIQUE-3 的简化。给定一个图 $G = ( V , E )$，其节点度以 3 为界，以及参数 b，我们通过保持图不变并将参数切换为 V b 来创建 CLIQUE-3 的实例。现在，当且仅当互补集 $V - C$ 是G中的团时，子集 $C \subseteq V$ 是G中的顶点覆盖。因此，当且仅当G具有大小为 $\geq | V | - b .$ 的团时，G具有大小为 $\leq b$ 的顶点覆盖。这证明了归约的正确性因此，CLIQUE-3 的 NP 完备性。

(d) 描述 CLIQUE-3 的 O(V 4) 算法。

</Exercise>

<Exercise title="Exercise 8.21">

通过杂交测序。一种用于识别新 DNA 序列的实验程序会重复探测它，以确定它包含哪些 k-mers（长度为 k 的子串）。基于这些，必须重建完整的序列。

现在让我们将其表述为一个组合问题。对于任何字符串 x（DNA 序列），令 $\Gamma ( x )$ 表示其所有 k-mers 的多重集。特别是， Γ(x) 恰好包含 $| x | - k + 1$ 个元素。

重构问题现在很容易表述：给定一个 k 长度字符串的多重集，找到一个字符串 x 使得 Γ(x) 正是这个多重集。

(a) 表明重建问题简化为 RUDRATA PATH。 （提示：构造一个有向图，每个 k 聚体有一个节点，如果 a 的最后 $k - 1$ 字符与 b 的前 k 1 个字符匹配，则构造一个从 a 到 b 的边。）

(b) 但事实上，还有更好的消息。表明同样的问题也可以简化为 EULER PATH。 $\operatorname { ( } H i n t { \mathrm { : } }$ 这次，为每个 k 聚体使用一个有向边。）

</Exercise>

<Exercise title="Exercise 8.22">

在任务调度中，通常使用图形表示，每个任务都有一个节点，如果 i 是 j 的前提条件，则使用从任务 i 到任务 j 的有向边。该有向图描述了调度问题中的优先约束。显然，当且仅当图是非循环时，时间表才是可能的。如果不是，我们希望确定必须删除的最小数量的约束，以使其成为非循环。

(a) 证明 FAS 处于 NP 状态。

$( w _ { i } , w _ { i } ^ { \prime } )$ 所有人 $i = 1 , 2 , \dots , n$

$( w _ { i } ^ { \prime } , w _ { j } )$ 和 $( w _ { j } ^ { \prime } , w _ { i } )$ 对于每个 $( v _ { i } , v _ { j } ) \in E$

(b) 证明如果 G 包含大小为 $b ,$ 的顶点覆盖，则 $G ^ { \prime }$ 包含大小为 $b .$ 的反馈弧集

(c) 证明如果 $G ^ { \prime }$ 包含大小为 $b ,$ 的反馈弧集，则 $G$ 包含大小为（最多）b的顶点覆盖。 （提示：给定 $G ^ { \prime }$ 中大小为 b 的反馈弧集，您可能需要首先稍微修改它以获得另一个更方便的形式，但大小相同或更小。然后，认为 G 必须包含与修改后的反馈弧集大小相同的顶点覆盖。）
