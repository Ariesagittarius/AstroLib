## 解答题

<Exercise title="习题 4.3.1">
惯性系 $S'$ 相对另一惯性系 S 沿 x 轴做匀速直线运动，取两坐标原点重合时刻作为计时起点。在 S 系中测得两事件的时空坐标分别为 $x_{1}=6\times10^{4}$ m, $t_{1}=2\times10^{-4}$ s，以及 $x_{2}=12\times10^{4}$ m, $t_{2}=1\times10^{-4}$ s。已知在 $S'$ 系中测得这两事件同时发生。试问：
(1) $S'$ 系相对 S 系的速度是多少？
(2) $S'$ 系中测得的两事件的空间间隔是多少？
</Exercise>

<Exercise title="习题 4.3.2">
长度 $l_{0}=1\ m$ 的米尺静止于 $S'$ 系中，与 $x'$ 轴的夹角 $\theta'=30^{\circ}$ ， $S'$ 系相对 S 系沿 x 轴运动，在 S 系中观测者测得米尺与 x 轴的夹角 $\theta=45^{\circ}$ 。试求：
(1) $S'$ 系和 S 系的相对运动速度；
(2) S 系中测得的米尺长度.
</Exercise>

<Exercise title="习题 4.3.3">
两个惯性系中的观察者 O 和 O' 以 0.6c (c 表示真空中的光速) 的相对速度相互接近, 如果观察者 O 测得两人的初始距离是 20 m, 则观察者 O' 测得两人经过多长时间相遇?
</Exercise>

<Exercise title="习题 4.3.4">
观测者甲、乙分别静止于两个惯性系 S 和 $S'$ 中，甲测得在同一地点发生的两事件的时间间隔为 4 s，而乙测得这两个事件的时间间隔为 5 s。求：
(1) $S'$ 系相对于S系的运动速度；
</Exercise>

<Exercise title="习题 4.3.5">
6 000 m 的高空大气层中产生了一个 $\pi$ 介子，以速率 v = 0.998c 飞向地球。假定该 $\pi$ 介子在其自身的静止系中的寿命等于其平均寿命 $2 \times 10^{-6}$ s。试分别从地球上的观测者和 $\pi$ 介子静止系中的观测者来判断该 $\pi$ 介子能否到达地球。
</Exercise>

<Exercise title="习题 4.3.6">
设物体相对 $S'$ 系沿 $x'$ 轴正方向以速率 0.8c 运动，如果 $S'$ 系相对 S 系沿 x 轴正方向的速率也是 0.8c，则物体相对 S 系的速率是多少？
</Exercise>

<Exercise title="习题 4.3.7">
飞船 A 以 0.8c 的速率相对地球向正东飞行，飞船 B 以 0.6c 的速率相对地球向正西飞行。当两飞船即将相遇时，飞船 A 在自己的天窗处相隔 2 s 发射两颗信号弹。在飞船 B 中的观测者测得两颗信号弹的时间间隔为多少？
</Exercise>

<Exercise title="习题 4.3.8">
(1) 火箭 A 和 B 分别以 0.8c 和 0.6c 的速率相对地球沿 x 轴正、负方向飞行。试求由火箭 B 测得的火箭 A 的速率。(2) 若火箭 A 相对地球以 0.8c 的速率沿 y 轴正方向运动，火箭 B 的速率不变，求 A 相对 B 的速率。
</Exercise>

<Exercise title="习题 4.3.9">
静止在 S 系中的观测者测得一光子沿与 x 轴成 $60^{\circ}$ 角的方向飞行。另一观测者静止于 $S'$ 系， $S'$ 系的 $x'$ 轴与 x 轴一致，并以 0.6c 的速率沿 x 轴方向运动。 $S'$ 系中的观测者观测到的光子的运动方向如何？
</Exercise>

<Exercise title="习题 4.3.10">
(1) 如果将电子由静止加速到速率为 $0.1c$ ，须对它做多少功？(2) 如果将电子由速率为 $0.8c$ 加速到 $0.9c$ ，又须对它做多少功？
</Exercise>

<Exercise title="习题 4.3.11">
$\mu$ 子的静止质量是电子静止质量的207倍，静止时的平均寿命 $\tau_0 = 2\times 10^{-6}\mathrm{s}$ ，若它在实验室参考系中的平均寿命 $\tau = 7\times 10^{-6}\mathrm{s}$ ，则其质量是电子静止质量的多少倍？
</Exercise>

<Exercise title="习题 4.3.12">
一物体的速度使其质量增加了 $10\%$ ，此物体在运动方向上缩短了百分之多少？
</Exercise>

<Exercise title="习题 4.3.13">
氢原子的同位素氘 $\left(\frac{2}{1}\mathrm{H}\right)$ 和氚 $\left(\frac{3}{1}\mathrm{H}\right)$ 在高温条件下发生聚变反应，产生氦 $\left(\frac{4}{2}\mathrm{He}\right)$ 原子核和一个中子 $\left(\frac{1}{0}\mathrm{n}\right)$ ，并释放出大量能量，其反应方程为
$$
{ } _ { 1 } ^ { 2 } \mathrm{H} + { } _ { 1 } ^ { 3 } \mathrm{H} \rightarrow { } _ { 2 } ^ { 4 } \mathrm{He} + { } _ { 0 } ^ { 1 } \mathrm{n}
$$
已知氘核的静止质量为 2.0135 amu(1 amu = 1.660 × 10 $^{-27}$ kg)，氚核、氦核及中子的质量分别为 3.0155 amu、4.0015 amu、1.00865 amu。求上述聚变反应释放出来的能量。
</Exercise>

<Exercise title="习题 4.3.14">
要使电子的速率从 $1.2 \times 10^{8}$ m/s 增加到 $2.4 \times 10^{8}$ m/s，必须做多少功？
</Exercise>

<Exercise title="习题 4.3.15">
粒子的静止质量为 $m_{0}$ ，当其动能等于其静能时，其质量和动量各等于多少？
</Exercise>

<Exercise title="习题 4.3.16">
太阳的辐射能来自其内部的核聚变反应. 太阳每秒向周围空间辐射出的能量约为 $5 \times 10^{26}$ J, 基于这个原因, 太阳每秒减少多少质量? 把这个质量同太阳目前的质量 $2 \times 10^{30}$ kg 作比较, 估算太阳的寿命是多少年.
</Exercise>
