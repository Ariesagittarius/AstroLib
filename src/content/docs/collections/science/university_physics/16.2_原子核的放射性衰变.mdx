## 16.2.1 原子核的稳定性

原子核的稳定性,是指原子核不会自发地改变其质子数、中子数和它的基本性质.原子核按照稳定性可分为稳定原子核和不稳定(或放射性)原子核两类.以下的经验与规则可帮助我们预测原子核的稳定性.

（1）质子数等于和大于84的原子核是不稳定的.即原子序数为84以后的元素均为放射性元素.

(2) 具有少于 84 个质子的原子核, 质子数和中子数均为偶数时, 原子核稳定.

（3）质子数或中子数等于2、8、20、28、50、82、126的原子核特别稳定.这些数称为幻数.例如， $\frac{4}{2}\mathrm{He},\frac{16}{8}\mathrm{O}$ 很稳定，质子数和中子数都是幻数，称为双幻数核.天然放射性元素最后的稳定产物都是铅 ${}_{82}^{208}\mathrm{Pb}$ ，也是双幻数核.

(4) 在 $Z < 20$ 时, 中子数和质子数之比 $\frac{n}{p} = 1$ , 原子核稳定. 随着原子序数的增加, $\frac{n}{p}$ 的值增大. $Z$ 为中等数值时, $\frac{n}{p}$ 约为 1.4; $Z$ 为 90 左右时, $\frac{n}{p}$ 约为 1.6. $\frac{n}{p}$ 的值越大, 原子核的稳定性越差.

## 16.2.2 原子核衰变

不稳定的原子核都会自发地转变成另一种核，同时放出射线，这种变化叫作放射性衰变.实验

发现,原子核在衰变过程中放出的射线有三种: $\alpha$ 射线、 $\beta$ 射线和 $\gamma$ 射线.

$\alpha$ 射线是 $\alpha$ 粒子流，它是带正电的氦核 ${}_{2}^{4}\mathrm{He}$ 。例如，镭核（ ${}_{88}^{226}\mathrm{Ra}$ ）衰变成氡核（ ${}_{86}^{222}\mathrm{Rn}$ ）的过程中放出 $\alpha$ 粒子，这一过程可表示为

$$

{ } _ { 8 8 } ^ { 2 2 6 } \mathrm{Ra} \rightarrow { } _ { 8 6 } ^ { 2 2 2 } \mathrm{Rn} + { } _ { 2 } ^ { 4 } \mathrm{He}

$$

$\beta$ 射线是高速运动的电子流. $\beta$ 衰变有 $\beta^{+}$ 和 $\beta^{-}$ 两种. $\beta$ 衰变时除放出 $e^{+}$ 或 $e^{-}$ 外, 还放出中微子 $\nu$ 或反中微子 $\bar{\nu}$ . 例如, 钴核 $(\frac{60}{27} \mathrm{Co})$ 衰变成镍核 $(\frac{60}{28} \mathrm{Ni})$ 的过程中放出 $\beta$ 射线, 即

$$

{ } _ { 2 7 } ^ { 6 0 } \mathrm{Co} \rightarrow { } _ { 2 8 } ^ { 6 0 } \mathrm{Ni} + { } _ { - 1 } ^ { 0 } \mathrm{e} + \bar { \nu } _ { \mathrm{e} }

$$

发生 $\beta^{-}$ 衰变时，原子核内中子转变成质子（留在核内），同时放出一个电子 $(e^{-})$ 和与电子相联系的反中微子 $\bar{\nu}_{e}$ ，即

$$

{ } _ { 0 } ^ { 1 } \mathrm{n} \rightarrow { } _ { 1 } ^ { 1 } \mathrm{p} + { } _ { - 1 } ^ { 0 } \mathrm{e} + \bar { \nu } _ { \mathrm{e} }

$$

发生 $\beta^{+}$ 衰变时，原子核内中子数较少，质子转变成中子（留在核内），同时放出一个正电子 $\mathrm{e}^{+}$ 和一个中微子 $\nu_{\mathrm{e}}$ ，即

$$

{ } _ { 1 } ^ { 1 } \mathrm{p} \rightarrow { } _ { 0 } ^ { 1 } \mathrm{n} + { } _ { + 1 } ^ { 0 } \mathrm{e} + \nu _ { \mathrm{e} }

$$

$\beta^{+}$ 衰变发生在人工放射性同位素中,例如

$$

{ } _ { 1 5 } ^ { 3 0 } \mathrm{P} \rightarrow { } _ { 1 4 } ^ { 3 0 } \mathrm{Si} + { } _ { + 1 } ^ { 0 } \mathrm{e} + \nu _ { \mathrm{e} }

$$

人们最初认为中微子 $\nu$ 和反中微子 $\bar{\nu}$ 的静止质量为零，近年的研究指出，中微子仍有静止质量。1979年，实验测得电子中微子 $\nu_{\mathrm{e}}$ 的质量是 $30\sim 40\mathrm{eV}$

$\gamma$ 射线是光子流. 通常是在 $\alpha$ 衰变或 $\beta$ 衰变后形成新核时辐射出来. 这是因为放射性母核经上述衰变后, 变成处于激发态的子核, 子核在跃迁到正常态时, 一般辐射出 $\gamma$ -光子. 例如, 母核镭 $(^{226}_{88}\mathrm{Ra})$ 发生 $\alpha$ 衰变后, 子核氡 $(^{222}_{86}\mathrm{Rn})$ 发出 $\gamma$ 射线后回到正常态.

放射性衰变过程,总是遵循电荷守恒、质量数守恒、能量守恒、动量守恒、角动量守恒等守恒定律.因此,衰变前粒子的电荷总数和质量总数与衰变后所有粒子的电荷总数和质量总数相等.用 $\frac{A}{2}X$ 表示衰变前的母核,衰变后子核的元素符号用Y表示,则 $\alpha$ 衰变一般可表示为

$$

{ } _ { Z } ^ { A } \mathrm{X} \rightarrow { } _ { Z - 2 } ^ { A - 4 } \mathrm{Y} + { } _ { 2 } ^ { 4 } \mathrm{He}\tag{16.12}

$$

对 $\beta$ 衰变,一般可表示为

$$

{ } _ { Z } ^ { A } \mathrm{X} \rightarrow { } _ { Z + 1 } ^ { A } \mathrm{Y} + { } _ { - 1 } ^ { 0 } \mathrm{e} + \bar { \nu } _ { e }

$$

或

$$

{ } _ { Z } ^ { A } \mathrm{X} \rightarrow { } _ { Z - 1 } ^ { A } \mathrm{Y} + { } _ { + 1 } ^ { 0 } \mathrm{e} + \nu _ { \mathrm{e} }\tag{16.13}

$$

式(16.12)和式(16.13)分别称为 $\alpha$ 衰变和 $\beta$ 衰变的位移定则. $\beta$ 衰变必同时放出中微子, 中微子的自旋为 $\frac{1}{2}$ , 以保证衰变前后角动量守恒和能量守恒.

## 16.2.3 放射性衰变定律

设有某种放射性同位素样品，单独存在时，某时刻 $t$ 样品中有 $N$ 个核.在 $t\sim t + \mathrm{d}t$ 时间内，有 $\mathrm{d}N$ 个核发生衰变， $\mathrm{d}N$ 应与 $\mathrm{dt}$ 成正比，与 $t$ 时刻的核数 $N$ 成正比，则

$$

- \mathrm{d} N = \lambda N \mathrm{d} t

$$

或

$$

\frac {\mathrm{d} N}{N} = - \lambda \mathrm{d} t\tag{16.14}

$$

式中， $\lambda$ 是表征衰变快慢的比例常数，叫作衰变常量。负号表示原子核数在减少。设 $t = 0$ 时， $N = N_0$ ，将式(16.14)积分，得

$$

N = N _ {0} \mathrm{e} ^ {- \lambda t}\tag{16.15}

$$

式 $(16.15)$ 称为放射性衰变定律.

把式 $(16.14)$ 写成

$$

\lambda = \frac {- \mathrm{d} N / \mathrm{d} t}{N}

$$

表明衰变常量 $\lambda$ 的物理意义是: 在 $t$ 时刻, 单位时间衰变的原子核数与该时刻原子核总数的比. 也可以说 $\lambda$ 是表征单位时间原子核衰变的概率. $\lambda$ 越大, 衰变越快.

习惯上常用半衰期来表征放射性元素衰变的快慢. 半衰期的定义是: 原子核由 $N_{0}$ 衰变到 $N = \frac{1}{2} N_{0}$ 所需的时间用 $T_{\frac{1}{2}}$ 表示. 由式(16.15)有

$$

\frac {1}{2} N _ {0} = N _ {0} \mathrm{e} ^ {- \lambda T \frac {1}{2}}

$$

于是有

$$

T _ {\frac {1}{2}} = \frac {\ln 2}{\lambda} = \frac {0 . 6 9 3}{\lambda}\tag{16.16}

$$

可见半衰期 $T_{\frac{1}{2}}$ 越短, 原子核衰变越快.

有时也用平均寿命 $\tau$ 表示衰变的快慢. 平均寿命是指每个原子核衰变前存在的时间的平均值. 可用如下方法求得: 在 $t \to t + \mathrm{d}t$ 时间内衰变的原子核数为 $-\mathrm{d}N$ (用负号是因为 $\mathrm{d}N$ 是负值), 存在的时间是 $t$ , 它们的寿命之和是 $t(-\mathrm{d}N)$ ; 对全部时间积分, 得到所有原子核的寿命之和为

$$

L = \int t (- \mathrm{d} N) = \int_ {0} ^ {\infty} t \lambda N \mathrm{d} t = \int_ {0} ^ {\infty} t \lambda N _ {0} \mathrm{e} ^ {- \lambda t} \mathrm{d} t = \frac {N _ {0}}{\lambda}

$$

因此，平均寿命 $\tau$ 为

$$

\tau = \frac {L}{N _ {0}} = \frac {1}{\lambda}\tag{16.17}

$$

平均寿命等于它的衰变常量的倒数.由式(16.16)知,平均寿命与半衰期的关系为

$$

\tau = \frac {T _ {\frac {1}{2}}}{\ln 2} = \frac {T _ {\frac {1}{2}}}{0 . 6 9 3}

$$

或

$$

T _ {\frac {1}{2}} = \ln 2 \tau = 0. 6 9 3 \tau

$$

自然界各种放射性元素的半衰期相差很大.有的元素的半衰期很长，如 $^{238}_{92}$ U的半衰期为 $4.5\times10^{9}$ a；有的元素的半衰期则很短，如 $^{212}_{84}$ Po的半衰期是 $3\times10^{-7}$ s.

放射性活度(也称放射性强度)是指一个放射源在单位时间内发生的核衰变次数 $\frac{dN}{dt}$ ，用I表示，由式(16.14)和式(16.15)省去负号可得

$$

I = \frac {\mathrm{d} N}{\mathrm{d} t} = \lambda N = \lambda N _ {0} \mathrm{e} ^ {- \lambda t}

$$

当 $t = 0$ 时， $N = N_0, I_0 = \lambda N_0$ ，则

$$

I = I _ {0} \mathrm{e} ^ {- \lambda t}\tag{16.18}

$$

在国际单位制(SI)中,放射性活度的单位是Bq(贝可勒尔).1 Bq表示每秒发生一次核衰变的放射源的活度.常用的单位还有Ci(居里)

$$

1 \mathrm{Ci} = 3. 7 \times 1 0 ^ {1 0} \mathrm{Bq}

$$

放射性活度相同的两个放射源, 只表示二者每秒发生的核衰变次数相同, 而不表示二者放出的粒子数相同. 因为每一次衰变不一定只放出一个粒子, 如钴-60 发生衰变时, 除放出一个 $\beta$ 粒子外, 还放出两个 $\gamma$ 光子.

<Example title="例 16.1">
已知某放射性元素在 5 min 内减少了 43.2%，求它的衰变常量、半衰期和平均寿命。

<Solution title="解">
根据衰变定律 $N = N_{0}\mathrm{e}^{-\lambda t}$ ，在 $t = 300~\mathrm{s}$ 时有 所以

$$

(1 - 43.2\%)N_{0} = N_{0}\mathrm{e}^{-\lambda t}

$$

$$

0. 5 6 8 = \mathrm{e} ^ {- \lambda t}

$$

$$

\lambda = \frac {1}{t} \ln \frac {1}{0 . 5 6 8} = 0. 0 0 1 8 8 \mathrm{s} ^ {- 1}

$$

利用式(16.16)，得

$$

T _ {\frac {1}{2}} = \frac {\ln 2}{\lambda} = 3 6 8 \mathrm{s}

$$

$$

\tau = \frac {1}{\lambda} = 5 3 2 \mathrm{s}

$$

放射性同位素有广泛的应用，并已深入多个学科领域。根据半衰期可算出地质年代，因此放射性同位素在考古学中有重要应用；在医学上，放射性同位素常用于放射性医疗、诊断；在农业上，放射性同位素常用于放射性育种；在工业上，放射性同位素常用于无损检测；等等。

<Example title="例 16.2">
已知 $^{40}$ K 衰变为 $^{40}$ Ar 的半衰期是 $1.28 \times 10^{9}$ a. 一块取自月球上的岩石经分析含 $^{40}$ K 8%、 $^{40}$ Ar 92%，试计算月球岩石的年龄.

<Solution title="解">
根据式(16.15)，得

$$

t = \frac {1}{\lambda} \ln \frac {N _ {0}}{N}

$$

由式(16.16)， $\frac{1}{\lambda}=T_{\frac{1}{2}}/\ln2$ ，所以

$$

t = \frac {T _ {\frac {1}{2}}}{\ln 2} \ln \frac {N _ {0}}{N}

$$

由题意得 $\frac{N_0}{N} = \frac{1}{8\%}$ , 代入上式, 则

$$

t = \frac {1 . 2 8 \times 1 0 ^ {9}}{0 . 6 9 3} \times \ln \frac {1}{0 . 0 8} \mathrm{a} = 4. 6 6 \times 1 0 ^ {9} \mathrm{a}

$$

该月球岩石的年龄约为46亿年.
