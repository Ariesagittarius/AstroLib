<Exercise title="习题 5.3.5">

</Exercise>

<Exercise title="习题 5.3.6">
一个沿 x 轴做简谐振动的弹簧振子, 振幅为 A, 周期为 T, 其振动方程用余弦函数表示. 如果 t = 0 时质点的状态分别是:
(1) $x_0 = -A$ ;
(2) 过平衡位置向 x 轴正方向运动；
(3) 过 $x = \frac{A}{2}$ 处且向 x 轴负方向运动；
(4) 过 $x = -\frac{A}{\sqrt{2}}$ 处且向 x 轴正方向运动.
试求出相应的初相位，并写出振动方程.
</Exercise>
