我们知道, 在三角形中, 如果已知 3 个元素 (非 3 个角), 那么利用正弦定理或余弦定理就能解出三角形中另外三个元素. 那么问题来了, 如果已知中三角形的元素没有给够 3 个, 给的只是关于边角的等式, 那么我们是否能利用正、余弦定理解三角形呢?

<Example title="例 2.7">
(2012 湖北理 11) 设 $\triangle ABC$ 的内角 A, B, C 所对的边分别为 a, b, c, 若 $(a + b - c)(a + b + c) = ab$ , 则 C = \_\_\_\_.

<Analysis>
已知条件只有一个关于边的等式, 即 $(a + b - c)(a + b + c) = ab$ , 因为边多角少, 不难想到应该利用余弦定理将已知关于边的等式转化为所求角.
</Analysis>

<Solution>
由 $(a + b - c)(a + b + c) = ab$ ，得 $a^2 + b^2 - c^2 = -ab$ ，由余弦定理得 $\cos C = \frac{a^2 + b^2 - c^2}{2ab} = \frac{-ab}{2ab} = -\frac{1}{2}$ . 又因为 $0 < C < \pi$ ，所以 $C = \frac{2\pi}{3}$ . 故填 $\frac{2\pi}{3}$ .
</Solution>
</Example>

观察 $(a + b - c)(a + b + c) = ab$ , 它是一个关于边的齐二次方程, 也就是说边的齐二次方程可以考虑通过余弦定理将边转成角. 但并不是所有边的齐二次方程都能求出角, 如果不能求出角, 我们的建议是通过已知再构造一个边的齐次方程, 然后联立解方程组, 请看以下例题:

<Example title="例 2.8">
(2015 浙江理 16 改编) 在 $\triangle ABC$ 中, 内角 A, B, C 所对的边分别为 a, b, c, 已知 $A = \frac{\pi}{4}$ , $b^{2} - a^{2} = \frac{1}{2}c^{2}$ . 则 $\tan C$ 的值为 \_\_\_.

<Solution>
因为 $A = \frac{\pi}{4}$ ，所以由余弦定理可得 $a^2 = b^2 + c^2 - 2bc\cos \frac{\pi}{4}$ ，即

$$
b ^ {2} - a ^ {2} = \sqrt {2} b c - c ^ {2}.\tag{2.2.1}
$$

又 $b^{2} - a^{2} = \frac{1}{2} c^{2}$ , 所以 $\sqrt{2} bc - c^{2} = \frac{1}{2} c^{2}$ , 解得 $b = \frac{3\sqrt{2}c}{4}$ , 将其代入式(2.2.1)得 $a = \frac{\sqrt{10}}{4} c$ , 于是

$$
\cos C = \frac {a ^ {2} + b ^ {2} - c ^ {2}}{2 a b} = \frac {\frac {5}{8} c ^ {2} + \frac {9}{8} c ^ {2} - c ^ {2}}{2 \times \frac {\sqrt {1 0}}{4} c \cdot \frac {3 \sqrt {2}}{4} c} = \frac {\sqrt {5}}{5}.
$$

因为 $C \in (0, \pi)$ , 所以 $\sin C = \sqrt{1 - \cos^2 C} = \frac{2\sqrt{5}}{5}$ , 因此 $\tan C = \frac{\sin C}{\cos C} = 2$ . 故填 2.
</Solution>
</Example>

在解三角形中, 我们一般有两种思路:

(1) 将所有的角都转成边, 然后对边进行运算; (2) 将所有的边都转成角, 然后进行三角恒等变换.

我们可以把 (1)(2) 概括为 “边角统一”, 尤其是已知条件中既有边, 又有角的情况, 而统一方法就是余弦定理和正弦定理.

<Example title="例 2.9">
(2016 山东文 8)△ABC 的内角 A, B, C 所对的边分别为 a, b, c. 已知 b = c, $a^{2} = 2b^{2}(1 - \sin A)$ ，则 $A = (\quad)$ .
A. $\frac{3\pi}{4}$ B. $\frac{\pi}{3}$ C. $\frac{\pi}{4}$ D. $\frac{\pi}{6}$

<Analysis>
因为 $a^2 = 2b^2 (1 - \sin A)$ 既有边, 又有角, 所以边角需统一, 又因为等式中含边的齐二次方程, 所以可以考虑利用余弦定理将 $\frac{a^2}{2b^2}$ 转成角.
</Analysis>

<Solution>
因为 b = c，所以 $\cos A = \frac{b^{2} + c^{2} - a^{2}}{2bc} = \frac{2b^{2} - a^{2}}{2b^{2}} = 1 - \frac{a^{2}}{2b^{2}}$ 。又因为 $a^{2} = 2b^{2}(1 - \sin A)$ ，变形得 $1 - \frac{a^{2}}{2b^{2}} = \sin A$ ，所以 $\sin A = \cos A$ ，即 $\tan A = 1$ ，又 $0 < A < \pi$ ，所以 $A = \frac{\pi}{4}$ ，故选 C.
</Solution>
</Example>

A. $\frac{3}{2}$ B. $\sqrt{2}$ C. $\frac{\sqrt{7}}{2}$ D. $\frac{\sqrt{3}}{2}$

通过前面的例题及其变式, 我们知道一些边的齐二次方程可以利用余弦定理将边转换成角. 同时, 三角形内角的余弦可以利用余弦定理将角转换成边. 对于更一般的边的齐次式, 我们可以利用正弦定理将边转换成角. 同样地, 三角形内角的正弦的齐次式可以将角转换成边, 即:

<Knowledge title="知识点 2.4">
由正弦定理 $\frac{a}{\sin A} = \frac{b}{\sin B} = \frac{c}{\sin C} = 2R$ 能够得到

(1) 边转角: 如果等式是关于边的齐次式, 那么根据 $a = 2R \sin A$ , $b = 2R \sin B$ , $c = 2R \sin C$ 可以将边转成角的正弦值.

(2) 角转边: 如果等式是关于内角正弦的齐次式, 那么根据 $\sin A = \frac{a}{2R}$ , $\sin B = \frac{b}{2R}$ , $\sin C = \frac{c}{2R}$ 可以将正弦值转成关于边的等式.
</Knowledge>

为什么要强调是齐次式才能边角转换呢？答案是只有齐次式才能将 $2R$ 约掉，例如 $a = b + c$ 是边的齐次式，利用正弦定理边转角得 $2R\sin A = 2R\sin B + 2R\sin C$ ，化简得 $2\sin A = \sin B + \sin C.$ 而 $a^2 = b + c$ 不是边的齐次式，利用正弦定理边转角得 $4R^2\sin^2 A = 2R\sin B + 2R\sin C,$ 化简得 $2R\sin^2 A = \sin B + \sin C,$ 化简后还是有 $R.$ 同理，利用正弦定理角转边，只有内角正弦的齐次式才能将 $R$ 约掉.

<Example title="例 2.10">
（2022 全国乙理 17(I)）记 $\triangle ABC$ 的内角 A, B, C 所对的边分别为 a, b, c，已知 $\sin C \sin(A - B) = \sin B \sin(C - A)$ . 证明: $2a^{2} = b^{2} + c^{2}$ .

<Solution>
由 $\sin C\sin (A - B) = \sin B\sin (C - A)$ 得

$$
\sin C \sin A \cos B - \sin C \cos A \sin B = \sin B \sin C \cos A - \sin B \cos C \sin A,
$$

整理得

$$
\sin A (\sin C \cos B + \sin B \cos C) = 2 \sin C \cos A \sin B.
$$

所以 $\sin A\sin (B + C) = 2\sin C\cos A\sin B,$ 化简得到齐次式为 $\sin^2 A = 2\sin C\cos A\sin B.$ 用正弦定理将角化边得 $a^2 = 2cb\cos A,$ 再用余弦定理将角化边得 $a^2 = 2bc\cdot \frac{b^2 + c^2 - a^2}{2bc}$ , 整理得 $2a^{2} = b^{2} + c^{2}$ .
</Solution>
</Example>

在利用余弦定理的边角转化中, 我们强调了边的齐二次式可以考虑利用余弦定理求角, 既然是边的齐次式, 我们当然也可以利用正弦定理将边转成角, 下面是例2.9的另一种解法:

<Example title="例 2.11">
(2016 山东文 8)△ABC 的内角 A, B, C 所对的边分别为 a, b, c. 已知 b = c, $a^{2} = 2b^{2}(1 - \sin A)$ ，则 $A = (\quad)$ .
A. $\frac{3\pi}{4}$ B. $\frac{\pi}{3}$ C. $\frac{\pi}{4}$ D. $\frac{\pi}{6}$

<Solution>
由 b = c，得 B = C，因此 $\sin A = \sin(B + C) = \sin 2B = 2\sin B\cos B$ 。又由 $a^{2} = 2b^{2}(1 - \sin A)$ ，得 $\sin^{2}A = 2\sin^{2}B(1 - \sin A)$ ，即 $4\sin^{2}B\cos^{2}B = 2\sin^{2}B(1 - \sin A)$ 。因为 $\sin B \neq 0$ ，所以 $2\cos^{2}B = 1 - \sin A$ ，即 $2\cos^{2}B - 1 = -\sin 2B$ ，化简得 $\tan 2B = -1$ 。又因为 B = C，所以 $B \in \left(0, \frac{\pi}{2}\right)$ ，即 $2B \in (0, \pi)$ ，于是 $2B = \frac{3\pi}{4}$ ，因此 $A = \pi - 2B = \frac{\pi}{4}$ 。故选 C。
</Solution>
</Example>

解三角形一个重要题型是判断三角形的形状, 一般此类问题我们有两种处理方法, 一种是边转角, 另一种是角转边, 请看下面的例题:

<Example title="例 2.12">
已知 a, b, c 分别是 $\triangle ABC$ 三个内角 A, B, C 的对边。若 $a \cos A = b \cos B$ ，试判断 $\triangle ABC$ 的形状。

<Solution title="解析1">
由 $a\cos A = b\cos B$ 及余弦定理得

$$
a \cdot \frac {b ^ {2} + c ^ {2} - a ^ {2}}{2 b c} = b \cdot \frac {a ^ {2} + c ^ {2} - b ^ {2}}{2 a c} \Rightarrow (a ^ {2} - b ^ {2}) (a ^ {2} + b ^ {2} - c ^ {2}) = 0.
$$

(i) 当 $a = b$ 时, $\triangle ABC$ 为等腰三角形;

(i) 当 $a \neq b$ 时, $a^2 + b^2 - c^2 = 0$ , 此时 $\triangle ABC$ 为直角三角形.

综上所述, $\triangle ABC$ 为等腰三角形或直角三角形.
</Solution>

<Solution title="解析2">
由 $a\cos A = b\cos B$ 及正弦定理得

$$
\sin A \cos A = \sin B \cos B \Rightarrow \sin 2 A = \sin 2 B.
$$

(i) 当 $2A = 2B$ , 即 $A = B$ 时, $\triangle ABC$ 为等腰三角形;

(i) 当 $2A = \pi - 2B$ , 即 $A + B = \frac{\pi}{2}$ 时, $\triangle ABC$ 为直角三角形.

综上所述, $\triangle ABC$ 为等腰三角形或直角三角形.
</Solution>
</Example>

判断三角形的形状关键在于边角互化, 正弦定理在齐次式中才能进行边角互化, 而余弦定理在边角互化没有齐次式这个条件限制. 判断三角形形状的前提在于是否可以构成三角形.

<Example title="例 2.13">
（2023 辽宁统考-多选题）已知 $\triangle ABC$ 内角 A, B, C 所对的边分别为 a, b, c，则下列条件一定能够使 $\triangle ABC$ 为等腰三角形的是（）.
A. $a \cos B = b \cos A$ B. $(a^{2} + b^{2}) \sin(A - B) = (a^{2} - b^{2}) \sin(A + B)$ C. $\cos B \cos C = \frac{1 - \cos A}{2}$ D. $\frac{a}{\sin B} + \frac{b}{\sin A} \leqslant 2c$

<Solution>
选项 A, 由 $a \cos B = b \cos A$ , 利用余弦定理把角化成边, 可得 $a \cdot \frac{a^2 + c^2 - b^2}{2ac} = b \cdot \frac{b^2 + c^2 - a^2}{2bc}$ , 整理得 $a^2 = b^2$ , 则 $a = b$ , 所以 $\triangle ABC$ 为等腰三角形, 故 A 选项正确.

选项 B, 将 $(a^{2}+b^{2})\sin(A-B)=(a^{2}-b^{2})\sin(A+B)$ 展开可得 $(a^{2}+b^{2})(\sin A\cos B-\cos A\sin B)=(a^{2}-b^{2})\sin C,$ 利用正弦定理把角化成边, 可得

$$
(a ^ {2} + b ^ {2}) (a \cos B - b \cos A) = (a ^ {2} - b ^ {2}) \cdot c.\tag{2.2.2}
$$

再把式(2.2.2)中的角的余弦化成边, 可得

$$
(a ^ {2} + b ^ {2}) \left(a \cdot \frac {a ^ {2} + c ^ {2} - b ^ {2}}{2 a c} - b \cdot \frac {b ^ {2} + c ^ {2} - a ^ {2}}{2 b c}\right) = (a ^ {2} - b ^ {2}) \cdot c,
$$

整理可得 $(a^2 - b^2)(a^2 + b^2 - c^2) = 0$ ，即 $a^2 + b^2 = c^2$ 或 $a = b$ ，则 $\triangle ABC$ 为等腰三角形或直角三角形故 B 选项错误.

选项 C, 由 $\cos B\cos C = \frac{1 - \cos A}{2}$ 可得 $2\cos B\cos C = 1 - \cos A$ , 又因为 $\cos A = -\cos (B + C)$ , 所以 $2\cos B\cos C = 1 + \cos (B + C)$ , 展开可得 $2\cos B\cos C = 1 + \cos B\cos C - \sin B\sin C$ , 即 $\cos B\cos C + \sin B\sin C = 1$ , 从而可知 $\cos (B - C) = 1$ . 又因为 $-\pi < B - C < \pi$ , 则 $B = C$ , 所以 $\triangle ABC$ 为等腰三角形, 故 C 选项正确.

选项 D, 由 $\frac{a}{\sin B} + \frac{b}{\sin A} \leqslant 2c$ , 利用正弦定理进行边化角, 可得 $\frac{\sin A}{\sin B} + \frac{\sin B}{\sin A} \leqslant 2\sin C$ , 又因为 $\frac{\sin A}{\sin B} + \frac{\sin B}{\sin A} \geqslant 2$ , 当且仅当 $A = B$ 时等号成立, 所以 $2 \leqslant 2\sin C$ . 又由 $\sin C \leqslant 1$ , 可得 $\sin C = 1$ , 此时 $A = B = \frac{\pi}{4}$ , $C = \frac{\pi}{2}$ , 所以 $\triangle ABC$ 为等腰三角形, 故 D 选项正确.

综上所述, 选 ACD.
</Solution>
</Example>

<Example title="例 2.14">
(2021 新高考 II 18(2)) 在 $\triangle ABC$ 中, 内角 $A, B, C$ 所对的边分别为 $a, b, c, b = a + 1$ , $c = a + 2$ . 是否存在正整数 $a$ , 使得 $\triangle ABC$ 为钝角三角形? 若存在, 求 $a$ ; 若不存在, 说明理由.

<Solution>
由 $b = a + 1, c = a + 2$ , 得 $c > b > a$ , 又因为三角形中大边对大角, 所以 $\triangle ABC$ 为钝角三角形时, $C$ 为钝角, 即 $a^2 + b^2 - c^2 < 0$ , 故 $a^2 + (a + 1)^2 - (a + 2)^2 < 0$ , 整理得 $a^2 - 2a - 3 < 0$ , 解得 $-1 < a < 3$ , 又 $a > 0$ , 所以 $0 < a < 3$ .

又因为三角形的任意两边之和大于第三边, 所以 $a + b > c$ , 即 $a + a + 1 > a + 2$ , 解得 $a > 1$ , 所以 $1 < a < 3$ , 结合 $a$ 为正整数知 $a = 2$ , 故存在正整数 $a = 2$ , 使得 $\triangle ABC$ 为钝角三角形.
</Solution>
</Example>

（2023 合肥一模）已知 $\triangle ABC$ 的内角 A, B, C 所对的边分别为 a, b, c, 且 $b^{2} + 2c^{2} - 2a^{2} = 0$ .

(I) 若 $\tan C = \frac{1}{3}$ , 求 $A$ ;

<Example title="例 2.15">
(2025 新高考 I 11-多选题) 已知 $\triangle ABC$ 的面积为 $\frac{1}{4}$ , 若 $\cos 2A + \cos 2B + 2\sin C = 2\cos A\cos B\sin C = \frac{1}{4}$ , 则 ( ).

A. $\sin^2 A + \sin^2 B = \sin C$ B. $AB = \sqrt{2}$ C. $\sin A + \sin B = \frac{\sqrt{6}}{2}$ D. $AC^2 + BC^2 = 3$

<Solution>
在处理解三角形或判断三角形形状的问题时, 我们通常希望能转化出角 $A, B, C$ 之间的某种关系. 因此, 对于题中所给的等式

$$
\cos 2 A + \cos 2 B + 2 \sin C = 2,
$$

我们考虑利用二倍角公式将其转化为关于 $A, B, C$ 的表达式. 可选的等式有 $\cos 2\alpha = 2\cos^2\alpha - 1$ 与 $\cos 2\alpha = 1 - 2\sin^2\alpha$ . 此处我们选择后者是因为能将等式右端的常数 2 抵消. 代入后得:

$$
1 - 2 \sin^ {2} A + 1 - 2 \sin^ {2} B + 2 \sin C = 2 \Longrightarrow \sin C = \sin^ {2} A + \sin^ {2} B.\tag{\textcircled{1}}
$$

因此, 选项 A 是正确的.

接下来问题的关键在于：是对这一式子进一步化简，还是转向题干中其余两个条件。显然，题干的另外两个条件不易化简，因此我们仍需围绕选项A所导出的结论继续深挖。

那我们能否进一步挖掘出这个等式所蕴含的三角形形状的信息呢？需要指出的是, 这一式子的两边并不对称. 如果所得为 $\sin^2 C = \sin^2 A + \sin^2 B$ , 那就“完美”了. 但注意到, 在三角形中, $\sin C \in (0,1]$ , 所以必有 $\sin C \geqslant \sin^2 C$ , 于是我们可以推出: $\sin^2 A + \sin^2 B \geqslant \sin^2 C$ . 结合正弦定理得 $a^2 + b^2 \geqslant c^2$ , 进而推出 $C \leqslant \frac{\pi}{2}$ .

由 $C \leqslant \frac{\pi}{2}$ 可知 $A + B \geqslant \frac{\pi}{2}$ , 所以 $A \geqslant \frac{\pi}{2} - B$ . 我们自然会想到对该不等式两边同时取正弦. 但此时需特别小心: 虽然常说 “三角形大角对大边”, 结合正弦定理可知角越大其正弦值也越大, 但这一结论仅适用于三角形的内角. 问题在于 $\frac{\pi}{2} - B$ 并不是一个三角形的内角, 因此无法直接比较 $\sin A$ 与 $\sin \left(\frac{\pi}{2} - B\right)$ . 我们需首先判断 $A$ 与 $B$ 的范围. 由题设条件 $\cos A \cos B \sin C = \frac{1}{4}$ 可知, $A$ 与 $B$ 必为锐角. 因此, 由 $A \geqslant \frac{\pi}{2} - B$ 可得 $\sin A \geqslant \sin \left(\frac{\pi}{2} - B\right) = \cos B$ , 将其代入式①可知

$$
\sin C = \sin^ {2} A + \sin^ {2} B \geqslant \cos^ {2} B + \sin^ {2} B = 1.
$$

因此必有 $\sin C = 1$ ，即必有 $C = \frac{\pi}{2}$

一旦得到 $C = \frac{\pi}{2}$ , 接下来的判断就容易许多, 即使是基础一般的同学也可顺利判断选项 B、C、D 的正误. 由于 $C = \frac{\pi}{2}$ , 代入式①和 $\cos A \cos B \sin C = \frac{1}{4}$ , 可整理出如下方程组:

$$
\left\{ \begin{array}{l} {\sin^ {2} A + \sin^ {2} B = 1} \\ {\cos A \cos B = \frac {1}{4}} \end{array} \right. \Longrightarrow \left\{ \begin{array}{l} {\sin^ {2} A + \sin^ {2} B = 1} \\ {\sin A \sin B = \frac {1}{4}} \end{array} \right.
$$

这里我们利用了 $A = \frac{\pi}{2} - B$ 和 $B = \frac{\pi}{2} - A$ . 实际上我们可以把 $\sin A$ 和 $\sin B$ 具体解出来, 不过观察 C 选项, 能看得出来这是标准的韦达结构:

$$
\sin A + \sin B = \sqrt {(\sin A + \sin B) ^ {2}} = \sqrt {\sin^ {2} A + \sin^ {2} B + 2 \sin A \sin B} = \sqrt {\frac {3}{2}} = \frac {\sqrt {6}}{2}.
$$

故选项 C 正确、

再来看选项 B 和 D. 我们再看题中尚未使用的信息: $\triangle ABC$ 的面积为 $\frac{1}{4}$ . 因为 $C = \frac{\pi}{2}$ , 所以 $ab = \frac{1}{2}$ , 由三角形中 $a = c\sin A, b = c\sin B$ , 代入得:

$$
a b = c ^ {2} \sin A \sin B = \frac {1}{2}.
$$

而 $\sin A\sin B = \frac{1}{4}$ ，代入得 $c^2 = 2$ ，即 $c = \sqrt{2}$ 故选项B正确.

最后看选项 D. 由于 $\triangle ABC$ 是以 $C$ 为直角的直角三角形, 所以由勾股定理可知 $AC^2 + BC^2 = AB^2$ , 即 $AC^2 + BC^2 = 2$ , 因此选项 D 错误.

综上所述, 选 ABC.
</Solution>
</Example>

从上述解析过程可以看出, 成功解答本题的关键在于如何在已知 $A$ 与 $B$ 均为锐角的前提下, 由条件 $\sin^2 A + \sin^2 B = \sin C$ 推出 $C = \frac{\pi}{2}$ . 值得一提的是, 这道题实际上是由三角函数中的一个重要恒等式改编而来.

<Summary title="结论总结 2.1">
设 A, B 均为锐角, 若 $\sin^{2}A + \sin^{2}B = \sin(A + B)$ , 则 $A + B = \frac{\pi}{2}$ .
</Summary>

<Block title="证明">
我们可以采用例2.15的解析来证明,这里我们换一种方式来证明.由题中条件可得

$$
\sin^ {2} A + \sin^ {2} B = \sin A \cos B + \cos A \sin B.
$$

化简上述式子 (移项并提取公因式) 得:

$$
\sin A (\sin A - \cos B) + \sin B (\sin B - \cos A) = 0.\tag{2.2.3}
$$

(1) 若 $A + B > \frac{\pi}{2}$ , 则 $\frac{\pi}{2} > A > \frac{\pi}{2} - B > 0$ . 由正弦函数在 $\left(0, \frac{\pi}{2}\right)$ 上单调递增, 可得 $\sin A > \sin \left(\frac{\pi}{2} - B\right) = \cos B$ ; 同理, 也有 $\sin B > \cos A$ . 因此, 式 ① 左边为两个正数之和, 其值大于 0, 与等式矛盾. 由此可知, 不能有 $A + B > \frac{\pi}{2}$ .

(2) 若 $A + B < \frac{\pi}{2}$ , 则 $0 < A < \frac{\pi}{2} - B < \frac{\pi}{2}$ , 由正弦函数在 $\left(0, \frac{\pi}{2}\right)$ 上单调递增, 可得 $\sin A < \sin \left(\frac{\pi}{2} - B\right) = \cos B$ ; 同理, 也有 $\sin B < \cos A$ . 因此, 式 ① 左边为两个负数之和, 其值小于 0, 与等式矛盾. 由此可知, 不能有 $A + B < \frac{\pi}{2}$ .

综上所述, $A+B=\frac{\pi}{2}$ .
</Block>

值得注意的是, 这里条件 $A, B$ 均为锐角是必要的, 否则就得不出 $A + B = \frac{\pi}{2}$ 的结论. 为说明这一点, 我们将结论总结2.1推广至如下:

<Summary title="结论总结 2.2">
设在 $\triangle ABC$ 中, 若

$$
\sin^ {2} A + \sin^ {2} B = \sin (A + B),
$$

则 $A + B = \frac{\pi}{2}$ 或 $\tan \frac{A + B}{2} = \tan^2\frac{A - B}{2}$ .
</Summary>

<Block title="证明">
记 $\alpha = \frac{A + B}{2},\beta = \frac{A - B}{2}$ ，则 $A = \alpha +\beta ,B = \alpha -\beta$ 因此，

$$
\begin{array}{r l} & {0 = \sin^ {2} A + \sin^ {2} B - \sin (A + B)} \\ & {\qquad = \sin^ {2} (\alpha + \beta) + \sin^ {2} (\alpha - \beta) - \sin 2 \alpha} \\ & {\qquad = (\sin \alpha \cos \beta + \cos \alpha \sin \beta) ^ {2} + (\sin \alpha \cos \beta - \cos \alpha \sin \beta) ^ {2} - \sin 2 \alpha} \\ & {\qquad = 2 (\sin^ {2} \alpha \cos^ {2} \beta + \cos^ {2} \alpha \sin^ {2} \beta - \sin \alpha \cos \alpha)} \\ & {\qquad = 2 [ \sin^ {2} \alpha \cos^ {2} \beta + \cos^ {2} \alpha \sin^ {2} \beta - \sin \alpha \cos \alpha (\sin^ {2} \beta + \cos^ {2} \beta) ]} \\ & {\qquad = 2 [ \sin \alpha \cos^ {2} \beta (\sin \alpha - \cos \alpha) + \cos \alpha \sin^ {2} \beta (\cos \alpha - \sin \alpha) ]} \\ & {\qquad = 2 (\sin \alpha - \cos \alpha) [ \sin \alpha \cos^ {2} \beta - \cos \alpha \sin^ {2} \beta ].} \end{array}
$$

(1) 若 $\sin \alpha = \cos \alpha$ , 则 $\alpha = \frac{\pi}{4}$ , 即 $A + B = \frac{\pi}{2}$ .

(2) 若 $\sin \alpha \cos^2 \beta = \cos \alpha \sin^2 \beta$ ，则 $\tan \alpha = \tan^2 \beta$ ，即 $\tan \frac{A + B}{2} = \tan^2 \frac{A - B}{2}$ .
</Block>

由结论总结2.2可见, 仅凭 $\sin^2 A + \sin^2 B = \sin (A + B)$ , 尚不足以推出 $A + B = \frac{\pi}{2}$ , 因为该式也可能导出另一结论: $\tan \frac{A + B}{2} = \tan^2 \frac{A - B}{2}$ .
