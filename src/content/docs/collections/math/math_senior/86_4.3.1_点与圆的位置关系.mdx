由两点间的距离公式, 很容易得到点和圆的位置关系判断方法, 内容如下所示:

<Knowledge title="知识点 4.15">
点 $P(x_{0}, y_{0})$ 与圆 $C: (x - a)^{2} + (y - b)^{2} = r^{2}$ 的位置关系：
(1) 当 $(x_{0}-a)^{2}+(y_{0}-b)^{2}>r^{2}$ 时，点 P 在圆 C 外；
(2) 当 $(x_{0}-a)^{2}+(y_{0}-b)^{2}=r^{2}$ 时，点 P 在圆 C 上；
(3) 当 $(x_{0}-a)^{2}+(y_{0}-b)^{2}<r^{2}$ 时，点 P 在圆 C 内.
</Knowledge>

<Example title="例 4.33">
(2023 安徽模拟) 若点 $(2a, a+1)$ 在圆 $x^{2} + (y-1)^{2} = 5$ 的内部，则实数 a 的取值范围是（）.

A. $(-1, 1)$ B. $(0, 1)$ C. $\left(-1, \frac{1}{5}\right)$ D. $\left(-\frac{1}{5}, 1\right)$

<Solution>
由题意可知 $(2a)^{2} + [(a + 1) - 1]^{2} < 5$ ，解得 $-1 < a < 1$ ，故选A.
</Solution>
</Example>

<Knowledge title="知识点 4.16">
直线 $\ell$ 过定点 P 且点 P 在圆 C 内, 则 $\ell$ 与圆必相交.
</Knowledge>

<Example title="例 4.34">
(2021 山东模拟) 已知动直线 $\ell$ 的方程为 $(m+1)x+(m-1)y+2m=0$ ，圆 $O:x^{2}+y^{2}=3$ ，则直线 $\ell$ 与圆 O 的位置关系是（）.

A. 相交    B. 相切    C. 相离    D. 无法确定

<Solution>
直线 $\ell$ 的方程可化为 $m(x + y + 2) + x - y = 0$ ，由 $\left\{ \begin{array}{l} x + y + 2 = 0 \\ x - y = 0 \end{array} \right.$ ，得 $\left\{ \begin{array}{l} x = -1 \\ y = -1 \end{array} \right.$ ，所以直线 $\ell$ 过定点 $(-1, -1)$ ，又 $(-1)^2 + (-1)^2 = 2 < 3$ ，即定点 $(-1, -1)$ 在圆 $O: x^2 + y^2 = 3$ 内，所以直线 $\ell$ 与圆 $O$ 的位置关系是相交，故选 A.
</Solution>
</Example>

A. 相离    B. 相切    C. 相交或相切    D. 相交

<Knowledge title="知识点 4.17">
(1) 若点 P 在圆 C 外, 则过 P 可以作 C 两条切线;

(2) 若点 $P$ 在圆 $C$ 上, 则过 $P$ 可以作 $C$ 一条切线.
</Knowledge>

<Example title="例 4.35">
(2023 山东期中) 过点 $P(2,1)$ 作圆 $C: x^{2} + y^{2} - ax + 2ay + 2a + 1 = 0$ 的切线有两条, 则 a 的取值范围为 \_\_\_\_.

<Solution>
方程 $x^{2}+y^{2}-ax+2ay+2a+1=0$ 表示圆，则 $a^{2}+4a^{2}-4(2a+1)>0$ ，解得 $a<-\frac{2}{5}$ 或 a>2。因为过点 P 作圆 C 的切线有两条，所以点 $P(2,1)$ 在圆 C 外，从而 $2^{2}+1^{2}-2a+2a+2a+1>0$ ，解得 a>-3。又因为 $a<-\frac{2}{5}$ 或 a>2，所以 $-3<a<-\frac{2}{5}$ 或 a>2，故填 $\left(-3,-\frac{2}{5}\right)\cup(2,+\infty)$ 。
</Solution>
</Example>

A. -1    B. -2    C. 1 或 2    D. -1 或 -2
