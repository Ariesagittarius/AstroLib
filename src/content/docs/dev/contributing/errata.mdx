---
title: 提交勘误
description: 使用页面内置反馈功能提交可定位、可复核的勘误。
---

阅读页面选中错误文本后，按 `Alt+F`，或点击页面中的反馈入口。反馈框会带上当前页面和选区上下文；请把“原文”“建议改为”“依据”写清楚。不要在 Issue 中粘贴 API Key 或私人信息。

好的勘误至少包含：

- 书名、章节和页内位置；
- 原文片段；
- 错误类型（公式、符号、图注、文字或链接）；
- 建议修正及推导依据；
- 若来自纸书，附纸书版本和页码。

提交后由维护者在源 MDX 中修正，再重新生成派生数据。反馈入口使用 GitHub Issue，不会直接修改线上正文。
