本文档介绍如何在阅读过程中使用 AstroLib 内置的交互工具直接提交勘误与排版修正建议。

---

## 1. 教材正文勘误（FeedbackMode）

AstroLib 内置了基于 AST 行号标记的读者勘误系统。读者在阅读章节正文或推导公式时，可随时定位并提交纠错。

### 1.1 唤起勘误模式
在任意教材阅读页面，通过以下两种方式之一激活勘误模式：
- **键盘快捷键**：按下 `Alt + F`
- **界面按钮**：点击顶栏右上角“九点工具箱”图标，在下拉面板中勾选“读者勘误模式”

激活后，页面顶部将出现勘误提示条，鼠标指针变为十字准星（`crosshair`）。

### 1.2 点选问题段落或公式
1. **行号探测**：将鼠标指针悬停在正文段落或独立数学公式上，元素周围将出现高亮虚线框，并浮现当前段落在源 `.mdx` 文件中的物理行号徽标（例如 `L42`）；
2. **公式级拾取**：若直接点击 KaTeX 数学公式，系统将自动提取其底层的 `data-latex` 源码；
3. **打开反馈弹窗**：点击高亮元素，界面将弹出勘误对话框。

### 1.3 填写与提交
- **选择错误分类**：错别字 / 标点、数学公式有误、缺少内容、排版瑕疵、其他建议；
- **填写修改建议**：在文本框中填写更正后的文字或标准 LaTeX 公式；
- **提交方式**：
  - **GitHub Issue 模式（默认）**：点击“在 GitHub 提交 Issue”，系统将自动生成格式化好的 GitHub Issue 页面（已自动填入文件名、行号、原文摘录与您的修正建议），确认后点击提交即可；
  - **免登录快捷模式**：若当前站点配置了反馈代理 Worker，可直接点击“一键提交”，由后台自动收录。

## 2. 习题与真题勘误

在右侧 Sideload 习题面板或全屏习题模态窗中，每道题目均支持独立的勘误上报通道。

### 2.1 报错入口
在任意题目卡片的右上角操作区，点击“报错/纠错”图标。

### 2.2 填写错误类型
在弹出的报错表单中选择问题所属维度：
- **题干有误**（stem）：公式缺失、文字错漏、条件模糊；
- **公式符号**（formula）：LaTeX 显示乱码、正负号颠倒、角标错位；
- **参考答案**（answer）：选项字母错误或计算结果不符；
- **考点映射**（kp）：所属章节或知识点归类有误；
- **其他说明**（other）。

### 2.3 提交与流转
填写详细说明后点击提交。数据将通过 `exerciseDb.submitFeedback()` 接口直接写入后台题库数据库并进入维护队列。若处于离线环境，反馈将保存在本地等待网络恢复。
