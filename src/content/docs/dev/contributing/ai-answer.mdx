---
title: 贡献 AI 答案
description: 如何从页面内置 AI 问答中整理出可审阅的答案贡献。
---

页面 AI 问答是 BYOK（自带 API Key）功能。提问时模型会先检索当前书籍的构建期索引，并在回答中尽量给出回到原章节的链接。AI 输出不是自动发布内容。

## 提交流程

1. 在书籍页面配置提供商和模型，提出一个边界清晰的问题。
2. 核对回答中的每个定义、公式、结论和章节链接；不要只凭语言流畅度判断正确。
3. 将可复用的答案改写为静态、可审阅的 MDX 内容，保留来源章节。
4. 对不确定内容标注待核验，不要把模型猜测写成定理或标准答案。
5. 通过正常 Pull Request 提交，并说明使用的模型、问题、引用章节和人工复核方式。

答案贡献应服务于正文和习题理解，不应加入分数、打卡或学习管理元素。模型密钥和完整私人对话不要提交。
