# 目录结构说明

AstroLib 项目采用了模块化的目录设计，明确划分了配置、组件、内容与处理脚本。

```text
my-astro-site/
├── .agents/                    # Agent Workspace 自动化技能与规范说明
│   └── skills/                 # 项目专属开发、导入与运维技能
├── docs/                       # 技术架构设计与历史交接文档
├── public/                     # 静态资源存放目录
│   ├── covers/                 # 图书封面图像资源
│   └── epub/                   # 生成的 EPUB 电子书产物
├── scripts/                    # 构建期工具脚本 (MDX 校验, EPUB 打包, RAG 索引构建)
├── src/
│   ├── components/             # Astro 界面组件与 Starlight Override 扩展件
│   │   ├── VpNav.astro         # 顶栏导航组件
│   │   ├── VpFooter.astro      # 页脚组件
│   │   ├── SidebarOverride.astro   # 左侧按书/按开发文档过滤侧边栏件
│   │   ├── PageSidebarOverride.astro # 右侧大纲与大纲指示器
│   │   └── Example.astro ...   # 11 种结构化教辅卡片组件
│   ├── config/                 # 中央配置目录 (唯一真理源)
│   │   ├── collections.config.mjs  # 合集、图书及模块主题映射配置
│   │   └── features.config.mjs     # 全站 Feature Registry 功能开关系统
│   ├── content/
│   │   └── docs/               # 平台 MDX 内容目录
│   │       ├── collections/    # 图书章节 MDX 文件
│   │       └── dev/            # 项目开发技术文档
│   ├── pages/                  # 自定义路由页面 (首页 index.astro, 检索页 library.astro)
│   ├── styles/                 # 样式系统
│   │   ├── custom.css          # 核心布局与微调样式
│   │   ├── vitepress-theme.css # VitePress 主题覆盖层
│   │   └── fonts.css           # 思源黑体/宋体 WebFont 定义
│   └── utils/                  # 工具函数与 Rehype 扩展插件
├── AGENTS.md                   # 开发者必须遵循的开发法则与约束
├── astro.config.mjs            # Astro 与 Starlight 核心配置文件
└── package.json                # 项目依赖定义
```
