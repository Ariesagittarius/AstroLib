# AstroLib 开发者技术文档

AstroLib 是一个面向大学理工科教材与学术资料的数字化阅读与自测系统。系统以严谨学术排版为核心，遵循“内容即界面（The Content is the Interface）”原则，消除无关的视觉噪声，使数学公式、推导过程与逻辑结构成为阅读的核心。

本文档集系统性地阐明了 AstroLib 的技术架构、快速上手流程、新书与题库贡献规范，以及针对开发辅助与 AI 系统的使用指南。

## 核心工程准则

> [!IMPORTANT]
> 1. **中央配置单源准则**：`src/config/collections.config.mjs` 为全站图书、合集及卡片模块配置的唯一源头。
> 2. **功能开关零打包**：全站功能受 `src/config/features.config.mjs` 统一调度，未启用功能在构建产物中实现零残留。
> 3. **Clean Slug 路由规范**：所有指向章节的链接生成均须经过 `cleanSlug()` 处理，禁止硬编码原始文件名。
> 4. **后台开发服务规范**：启动开发服务器推荐使用 `astro dev --background`，并通过 PID 锁文件安全控制。
