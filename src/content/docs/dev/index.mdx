# AstroLib 开发者技术文档

本系统基于 Astro 7 与 Starlight 框架构建，专为初高中及大学本科理科（数学、物理等）教材与教辅提供数字化整理、高质量 KaTeX 公式排版、结构化章节大纲及离线 EPUB 导出支持。

本文档集阐明系统的整体架构设计、配置管理规范、内容撰写标准及相关开发运维工具的使用说明。

## 核心开发约束

> [!IMPORTANT]
> 1. **中央配置单源原则**：`src/config/collections.config.mjs` 为全站图书、合集及卡片模块主题的唯一配置源。严禁向已废弃的 `books.config.mjs` 写入业务逻辑。
> 2. **功能开关控制约束**：功能插件受 `src/config/features.config.mjs` 统一调度。当关闭某项功能时，相关 CSS、插件及代码必须实现零打包残留。
> 3. **Clean Slug 路由规范**：所有指向章节的链接生成均须经过 `cleanSlug()` 处理，禁止硬编码原始文件名。
> 4. **后台开发服务规范**：启动开发服务器统一采用 `astro dev --background`，并通过 PID 锁文件控制运行状态。
