这组文档面向希望运行、维护或贡献 AstroLib 的读者。内容以仓库当前代码为准，命令默认在项目根目录执行。

## 推荐阅读顺序

1. [项目架构与能力](/dev/overview/)
2. [部署、运行与环境变量](/dev/getting-started/setup/)
3. [脚本索引与常用命令](/dev/getting-started/scripts/)
4. 按需要阅读[添加一本新书](/dev/getting-started/add-book/)、[加入一本习题册](/dev/getting-started/add-exercises/)或[贡献新的书籍](/dev/contributing/book/)

## 先说明两件事

- `src/config/collections.config.mjs` 是书籍目录的来源；不要另建一个平行的书籍配置。
- `public/` 只放浏览器直接访问的静态资源。构建产物、临时日志和导出中间文件请放在 `.tmp/` 或脚本约定的输出目录。

## 贡献前的最低检查

```powershell
npm install
npm run build
node scripts/scan-mdx.mjs src/content/docs/collections/<collection>/<book>
```

如果只修改文档页面，至少运行 `npm run build`，确认 Starlight 侧栏和 MDX 均可编译。
