本文档介绍 AstroLib 的书内 AI 问答体系，阐明如何利用 Model Context Protocol (MCP) 与端侧检索增强生成（RAG）消除大模型在理工科学术问答中的幻觉问题。

---

## 1. 为什么纯大模型在高等数学中频繁产生幻觉？

高等数学与物理学是一门由精确定义、推导前置条件与严密定理构成的演绎学科：
- **符号敏感度极高**：单侧极限（$x \to x_0^+$）与双侧极限的区别、可导与可微在多元情况下的非对等关系，稍有混淆即导致逻辑全盘崩溃；
- **前置定理条件易被遗漏**：大模型往往擅长文辞编排，但在具体推导时容易凭空编造定理名字或忽略定理成立的充分必要条件（例如在非正项级数中套用比值审敛法）；
- **缺乏版本与教材归属**：不同经典教材在符号体系与定理命名上存在微小差异（如柯西审敛原理在各教材中的章节编排差异）。

---

## 2. AstroLib 的解决方案：以 MCP 为基础的端侧证据链

为实现严格可信的学术答疑，AstroLib 拒绝让大模型“脱离教材凭空发挥”，而是将大模型置于“学术助教”角色。系统构建了一套端侧轻量工具链，遵循标准 **Model Context Protocol (MCP)** 规范。

在处理用户提问时，大模型必须先通过调用本地工具获取教材真实原文作为证据片段，方可组织推导并给出解答。

```text
用户提问（如：“请证明柯西中值定理，并列出本节对应的例题”）
                         │
                         ▼
             大语言模型分析意图与依赖
                         │
        ┌────────────────┴────────────────┐
        ▼                                 ▼
调用 search_book_content         调用 get_chapter_outline
  (检索原书对应推导切片)             (获取第三章小节大纲)
        │                                 │
        └────────────────┬────────────────┘
                         ▼
               返回精确证据与公式源码
                         │
                         ▼
       大模型结合证据片段生成学术级严密解答
       （答案内附带精确的章节跳转与公式出处锚点）
```

## 3. 全站 8 个端侧 MCP 工具规格

AstroLib 内置了 8 个端侧检索与元数据工具，由前端 Harness 控制器在浏览器端或本地运行：

| 工具名称 | 核心职责 | 输入参数 | 返回数据 |
| :--- | :--- | :--- | :--- |
| `search_book_content` | 在指定图书或全站正文中检索概念、定理与定义 | `query`, `book_slug`, `limit` | 匹配段落、卡片类型与所在物理章节 |
| `get_chapter_outline` | 提取指定书籍的目录树与知识小节结构 | `book_slug` | 章节编号、标题与对应 slug 列表 |
| `get_formula_by_tag` | 通过公式编号精准提取带 `\tag{...}` 的独立公式 | `tag`, `book_slug` | 完整的 KaTeX 原始公式代码与上下文 |
| `get_exercise_by_id` | 根据题目编号精准读取历年真题与官方解析 | `question_id` | 题干、选项、答案与官方步骤 |
| `query_knowledge_graph`| 查询某概念的前驱依赖与后继应用节点 | `concept_name`, `book_slug` | 关联概念节点列表与逻辑拓扑边 |
| `search_cross_references`| 查询某个定理在全书其他章节被引用的全量记录 | `target_id` | 引用该定理的所有章节与跳转锚点 |
| `list_books` | 获取当前书库收录的全部教材元数据 | 无 | 书名、作者、版次与学科分类 |
| `get_book_metadata` | 获取指定教材的详细出版与模块配置信息 | `book_slug` | ISBN、模块映射规则与统计信息 |

## 4. 客户端 Harness 调用树与可折叠呈现

为了让阅读界面保持清爽、不被冗长的大模型调用日志打扰，前端界面遵循 Material You 设计规范对 MCP 调用过程进行了深度收敛：
- **微型化调用树**：模型调用工具检索证据的过程被收拢在输入框下方的微型状态条中，以轻量状态徽标（如 `🔍 检索柯西中值定理...`）告知读者当前进展；
- **可溯源出处**：解答完成后，引用的教材段落、真题编号与定理出处统一以 Material 3 Assist Chip 形式附在答案末尾，点击即可直接平滑滚动定位至正文原处。
