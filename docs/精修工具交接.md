> ⚠️ **写回端点为什么不用 Astro middleware**（原 `src/middleware.ts` 已删除）：
> dev 模式下 `/__edit__/*` 请求不匹配任何具体页面路由，devMatch 会落到一条 **prerendered** 路由（`routeData.prerender === true`）。Astro 的 `createRequest` 在 `isPrerendered` 时会 **`url.search = ""`（清空 query）并把 body 置 null**，导致 middleware 拿不到 query 参数与 POST body——表现为 source/apply 全部报"缺少有效的 file / line""缺少 file / op"，而 health（无参数）正常。
> 修复方案：把端点放在 **Vite dev server 的 connect middleware 层**（`configureServer` 里 `server.middlewares.use`），它在 Astro 的 Request 构造（`astroDevHandler`，注册于 configureServer 后置钩子）**之前**执行，直接读原始 `req.url`（含 query）与 req body，彻底绕开该坑。

## 三、关键设计约定（改代码前必读）

### 行号空间（实测修正版，务必遵守）
- **注入层（data-src-line）= 全文行号**：Astro 编译 MDX 时 position 保留 frontmatter 偏移，M1 实测 h2 在全文第 14 行 → `data-src-line="14"`。
- **locateBlock / applyOp = body 行号**：`parseFile(content)` 剥离 frontmatter 后解析，mdast position 从 body 第 1 行起。
- **换算**：`bodyLine = 全文行号 - offset`（`offset = frontmatter 换行数`，见 parse.mjs `stripFrontmatter`）。**dev-server-plugin.mjs 的所有端点负责把前端传来的 line / targetLine（全文空间）换算成 body 空间后再调 locateBlock / applyOp**；前端拿 `data-src-line` 直接用，不做换算。

### 操作协议（POST /__edit__/apply，body: `{ file, op, payload }`）
- `replace-block { line, newText }`：整块替换（改文本/标题）
- `edit-formula { line, oldLatex, newLatex }`：行内/行间公式替换；块内多次出现则拒绝；**oldLatex/newLatex 均不含 `$` 分隔符**（行内自动拼 `$…$`、行间自动拼 `$$\n…\n$$`）。注意：页面 DOM 上 `data-latex` **含**分隔符，前端提交前需剥离（editor.ts 的 `stripDelimiters` 已处理）
- `move-block { line, targetLine, position: 'before'|'after' }`：块移动；源/目标互相嵌套时拒绝
- `unwrap { line }`：卡片 → 正文（剥 JSX 外壳）
- `extract { line }`：卡片内块移出到卡片之后（文本匹配定位，鲁棒）；**卡片内只剩这一个块时，删除空卡片、该块直接作为正文**（结果等同 unwrap，不再报错）
- `wrap { line, cardType, title }`：正文块 → 包成卡片；`cardType` 取 apply-op.mjs `COMPONENT_BY_KIND` 的 key：`example/variant/knowledge/note/solution/block/method/guide/exercise`（title 自动转义 `{ } " &`）
- `delete { line }`：删块并清理相邻空行
- 所有操作写回前用 `@mdx-js/mdx compile` 校验，失败拒绝写入；写盘保留原 CRLF/LF；undo 栈在 dev server 进程内存（每文件最多 50 条，**重启 dev server 即清空**）。

### 注入细节
- 卡片 = `mdxJsxFlowElement`（@mdx-js/mdx 的 passThrough）；正文块 = hast element（`BLOCK_KIND`：p/h2-6/ul/ol/table/blockquote/pre）。卡片内段落也注入。
- DOM 层级即块层级：前端 `closest('[data-src-line]')` 找块，向上找卡片 kind 祖先得所属卡片。
- 公式：`.katex[data-latex]`（行内）/ `.katex-display`（行间）由 rehype-katex-source.mjs 注入 `data-latex`（精确源码，含分隔符）。

### M2 前端约定
- 进入：URL `?edit=1` 或 `E` 键；退出更新 URL（`history.replaceState` 去 edit 参数）。
- SPA 导航（SidebarOverride 自定义 fetch+替换 main）后：监听 `astro:page-load` + `popstate` 清选中、重同步文件路径。
- 上移/下移仅对**同父容器兄弟块**生效（`:scope > [data-src-line]`）；卡片内段落的上移/下移按钮禁用。
- 编辑模式下点击块 `preventDefault` 阻止默认导航（链接/锚点），公式优先弹公式编辑。
- `#dsh-editor-root` 的 CSS：root `pointer-events: none`，`#dsh-editor-root *` 必须 `pointer-events: auto`，`.dsh-badge` / 普通 toast 例外（`none`）。

### 安全
- dev-server-plugin 仅在 `IS_DEV` 时注册（astro.config.mjs `vite.plugins`），生产构建零输出；file 必须解析到 `CONTENT_ROOT` 下且 `.mdx` 后缀（`safeResolve`）。
