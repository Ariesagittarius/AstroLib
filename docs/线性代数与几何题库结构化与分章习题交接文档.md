北京邮电大学精品教材《线性代数与几何（第2版）》（刘吉佑、徐勇编著，北京邮电大学出版社）全书理论正文（前言、第 1 章至第 9 章共 42 篇 MDX 章节）已 100% 完成视觉数字化重构与出版级验证。

```typescript

  /** 题目全局唯一 ID：LAG-TB-CH{章两位}-Q{题号两位}，如 "LAG-TB-CH01-Q01" */
  id: string;

  /** 来源类型：课后习题固定为 "textbook" */
  source_type: "textbook";

  /** 来源元数据 */
  source: {
    paper_id: number; // 编号约定：2000 + 章号，如第1章为 2001，第9章为 2009
    raw_title: string; // 如 "《线性代数与几何》第1章 行列式 课后习题"
    clean_title: string; // 同 raw_title
    category: string; // "教材课后习题"
    course_name: string; // "线性代数与几何"
    academic_year: string; // "教材配套"

    source_desc: string; // 如 "《线性代数与几何》第 1 章 · 习题一 第 1 题"

    page_end?: number; // 题目所在物理结束页，如 37

    paper_q_num: number; // 原书题号 (1..N)
    type: "calc" | "proof" | "choice" | "blank"; // 题型：计算、证明、选择、填空
    difficulty: number; // 难度分级：1(基础) / 2(中等) / 3(进阶) / 4(拔高)
    score: number; // 建议分值：计算 5 分，小问多题 8-10 分，大证明题 10-12 分
  };

  /** 教材知识图谱映射 */
  mapping: {
    linear_algebra_geometry: {
      chapter: number; // 章号 (1..9)
      chapter_title: string; // 如 "第1章 行列式"
      section?: string; // 关联小节编号，如 "1.1" 或 "1.2"（可选）
      section_title?: string; // 关联小节标题（可选）
      section_slug?: string; // 关联小节 MDX slug（可选）
      knowledge_points: string[]; // 考察知识点列表，如 ["三阶行列式", "对角线法则"]
    };
  };

  /** 题目题干与选项结构 */
  content: {
    stem: string; // 完整题干，数学公式用 $...$ 或 $$...$$ 包裹
    options?: Array<{ key: string; text: string }>; // 选择题选项（若有）
    sub_questions?: Array<{
      sub_id: string; // 如 "(1)", "(2)"
      stem: string; // 小问题干
      answer?: string; // 小问独立答案（若有）
    }>;
  };

  /** 参考答案与解析 */
  solution: {
    answer: string; // 原书标准参考答案（含 LaTeX 公式、数值、矩阵等）
    hints?: string; // 原书题目给出的提示（如 "提示:利用范德蒙德行列式的结果"）或解题思路点拨

  };
}
```

### 4.3 LaTeX 公式与 JSON 转义约束

1. **反斜杠双转义（Strict JSON Requirement）**：
   在写入 JSON 文件时，所有 LaTeX 反斜杠必须写为双反斜杠 `\\`，例如：
   `\\begin{pmatrix}`, `\\frac{a+c}{2}`, `\\boldsymbol{\\alpha}`, `\\lambda`。
2. **矩阵与行列式语法**：
   - 矩阵统一采用 `\begin{pmatrix} ... \end{pmatrix}`（圆括号）或 `\begin{bmatrix} ... \end{bmatrix}`（中括号），与原书排版习惯一致。
   - 行列式统一采用 `\begin{vmatrix} ... \end{vmatrix}`。
   - 换行统一用 `\\`（在 JSON 中转义后为 `\\\\`）。
3. **向量与符号体系**：
   - 希腊字母向量：`\boldsymbol{\alpha}` 或 `\alpha`，转置统一用上标 `^{\mathrm{T}}` 或 `^T`。
   - 伴随矩阵统一用 `A^*`，逆矩阵统一用 `A^{-1}`。
   - 内积：`(\boldsymbol{\alpha}, \boldsymbol{\beta})`。
4. **小问拆解原则**：
   - 若题目包含明确小问（如 `(1)`, `(2)`, `(3)`），在 `content.sub_questions` 中进行分项收录；
   - 答案对应的 `(1)`, `(2)` 亦可在 `sub_questions` 中直接写入 `answer`，同时在顶层 `solution.answer` 中完整呈现整题答案汇总。

## 6. 下一个 Agent 实操执行 SOP (Step-by-Step Implementation Guide)

建议下一个 Agent 采取 **“分章提取 → 即时对齐 → 写入主库 → 语法校验”** 的稳健迭代流程。

### 阶段一：准备与环境确认
1. 检查 Python 虚拟环境：`.venv\Scripts\python`，已具备 `pymupdf`、`json`、`re` 等工具。
2. 确认图片目录 `test/data/lag_pages/` 完好无损（239 页全部就绪）。

### 阶段二：逐章结构化提取（建议每批次处理 2~3 章）
对于每一章（例如第 1 章）：
1. **查看题目图片**：
   使用 `view_file` 调取题目物理页（如 `test/data/lag_pages/phys_37.jpg` 至 `phys_41.jpg`）。
2. **查看对应答案图片**：
   使用 `view_file` 调取答案物理页（如 `test/data/lag_pages/phys_219.jpg` 至 `phys_220.jpg`）。
3. **结构化转录**：
   - 提取各题原书题号、题干文本、内嵌公式；
   - 提取原书给出的 "提示"（如习题一第 11 题的 "提示:利用范德蒙德行列式的结果"），存入 `solution.hints`；
   - 提取答案区对应的参考答案，精准绑定至该题的 `solution.answer`；
   - 证明题若原书答案为 "证明略"，可在 `solution.answer` 填入 "证明略"，并在 `solution.steps` 补充精要推导思路（如 "构造辅助行列式并按第1列展开"）；
   - 正确判断题型（`calc` / `proof` / `choice` / `blank`）与估计难度（1~4）。
4. **生成中间 JSON**：
   可先保存在 `src/data/exercises/raw_lag/ch01.json` 等临时切片中，或直接合并进主 JSON。

### 阶段三：合并写入主库
将 9 个章节的题目数组统一组织进：
`src/data/exercises/linear_algebra_geometry_textbook_exercises.json`

确认顶层字段：
- `book`: `"linear_algebra_geometry"`
- `total_questions`: 253
- `chapters`: 包含 `"1"` 到 `"9"` 9 个键。

### 阶段四：静态切片生成（供运行时与侧载底座加速）
参考 [scripts/build-exercise-data.mjs](file:///d:/Antigravity/project/AstroLib/scripts/build-exercise-data.mjs)，编写或扩展构建脚本，将主库按章预编译 KaTeX 并切片至：

function testMath(str) {
  if (!str) return;
  const matches = str.match(/\\$\\$([\\s\\S]+?)\\$\\$|\\$([^\\$]+?)\\$/g) || [];
  for (const m of matches) {
    const raw = m.startsWith('$$') ? m.slice(2, -2) : m.slice(1, -1);
    try {
      katex.renderToString(raw, { throwOnError: true });
    } catch (e) {
      console.error('KaTeX error in formula:', raw, e.message);
      mathErrors++;
    }
  }
}
