# 贡献 AI 题解

很多历年名校期中期末真题与教材高阶练习题仅给出了最终参考数值或简略答案，缺乏细致的分步推导过程。AstroLib 允许读者使用个人配置的大语言模型生成规范推导，并将优质解答共享到全站题库供其他读者参考。

---

## 1. 触发 AI 规范推导

1. **进入习题**：在章节末尾点击 `<ExerciseTrigger>` 或在顶栏打开习题中心；
2. **点击推导**：在目标题目卡片底部，点击带有星标的“**AI 规范推导**”按钮；
3. **流式生成**：系统将结合题目元数据（题干、选项、题型与参考答案）组装学术导师 System Prompt，调用您在本地配置的推理模型（如 DeepSeek V4.1 Flash 或 Gemini 3.8 Flash）进行流式演算；
4. **公式即时渲染**：推导过程中的 Markdown 与 KaTeX 数学公式将以 100ms 批处理节流调度器平滑渲染上屏。

---

## 2. 审阅与核对

推导完成后，卡片顶部工具栏将出现以下操作辅助审阅：

- **浮窗对照（M3 Rich Tooltip）**：点击弹出图标，可将完整解答悬浮在题目左侧，方便将演算步骤与原题条件逐行对照；
- **查看思路演进**：若选用具备深度思考的模型，可展开“思考过程”折叠栏，核对模型的思路推演路径；
- **复制 Markdown 源码**：点击复制图标，可将包含完整公式的 Markdown 题解一键存入剪贴板。

---

## 3. 上传共享至社区题解库

若您认为当前生成的推导过程逻辑严谨、步骤完整，可直接将其共享：

1. **点击上传按钮**：在题解面板操作栏点击“共享此题解”；
2. **填写元数据**：
   - **贡献者署名**：填写您的昵称或 GitHub 用户名（留空则默认为“热心读者”）；
   - **推导模型名称**：系统会自动填入当前运行的模型标称（如 `DeepSeek-V4.1-Flash` 或 `Gemini-3.8-Flash`）；
   - **解题备注**：可补充说明本题的核心考点或技巧（例如“利用拉格朗日中值定理与放缩法求解”）；
3. **确认提交**：点击确认后，数据将通过 `exerciseDb.uploadCommunitySolution()` 上传至题库数据库。

---

## 4. 社区题解查阅与互动

- **多模型对比**：其他读者在做这道题时，可展开“社区推导”列表，查阅不同读者利用不同模型给出的解答路线；
- **点赞机制**：读者可为步骤最严谨、推导最清晰的题解点赞，高赞题解将在列表中优先展示；
- **防刷机制**：系统通过客户端哈希去重，防止重复点赞。
