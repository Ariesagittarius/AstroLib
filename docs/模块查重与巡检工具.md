# 书籍模块巡检与查重工具（Module Inspector）

> 开发期专属工具：在 `astro dev` 模式下，快速查看、全文检索与多维度查重当前书籍内的所有卡片模块（例题、变式、知识点、结论、定理、定义、习题、解析等），并支持一键精准跳转定位与联动在线精修工具。生产构建零打包、零注入。

---

## 一、背景与设计目标

在理科教辅与教材的数字化清洗过程中，由于 OCR 识别与文本切分规则边界局限，经常会出现以下结构性问题：
1. **正文语句被误拆为卡片模块**：例如正文中的“例1说明”、“例题 2 分析”被误识别拆分成独立的 `<Example title="例 1">说明...</Example>`，破坏了正文连贯性并产生多余的重名模块。
2. **同章节内同名重复**：同一节内出现多个“例 1”或重复的“定理 1.1”，容易导致大纲索引混淆与锚点冲突。
3. **内容截断碎片**：空卡片或仅有几个字符的残缺卡片碎片。

本工具作为与 `epub`、`editor`、`aiAsk` 同一级的特性模块（`inspector`），提供开箱即用的可视化巡检抽屉，帮助开发者在浏览器内即时筛查、定位与纠偏。

---

## 二、功能特性

### 1. 全书模块实时概览与检索
- **实时扫描**：直接由 Vite connect middleware 从本地 MDX 章节磁盘文件实时解析提取，速度仅需 10~30ms，无需重新编译。
- **书籍切换**：默认自动识别当前浏览的书籍（根据 URL 路由），亦可通过下拉框自由切换全站任意书籍。
- **全文搜索**：支持对模块标题、正文片段、章节名、源码行号进行实时高亮过滤。
- **分类筛选**：支持按卡片类型（例题、知识点、定理、习题、解析等）和按指定章节进行多重组合筛选。

### 2. 多维度查重与异常检测

| 视图 Tab | 作用 | 重点检测内容 |
|---|---|---|
| **📋 全部模块** | 顺序查看当前书籍所有卡片模块 | 模块总览、卡片类型统计、全文检索与章节过滤 |
| **🚨 同章重复** | **最高优先级异常** | 同一章节（MDX 文件）内出现的重名模块（如 2 个“例 1”或重复“性质 1.3.4”），直接分组展示各处位置与正文预览 |
| **🔁 全书重名** | 全书跨章节重名聚合 | 按归一化标题分组聚合，统计全书出现频次与跨章节分布 |
| **⚠️ 疑似异常** | 重点筛查 OCR 切分误伤 | 1. 标题含“说明/注意/解析/分析/注”的例题卡片（疑似正文误拆）；<br>2. 标题字符过长（>30 字符，疑似误吞正文）；<br>3. 正文极短（<6 字符，疑似空壳碎片）；<br>4. 缺少 title 属性的卡片。 |

### 3. 一键跳转定位与高亮（Jump & Pulse）
- **同页跳转**：点击模块卡片的「🎯 跳转」按钮，页面将平滑滚动至对应卡片中央，并附加 2.5 秒的柔和波纹脉冲高亮（`dsh-inspector-pulse`）。
- **跨章节跳转**：无缝调用站点 SPA 路由无刷新跳转至目标章节，并在新页面载入后精确定位与高亮。
- **复制文件路径**：一键复制形如 `src/content/docs/collections/math/math_senior/06_xxx.mdx:L45`，便于在 IDE / VS Code 中快速定位跳转。
- **联动在线精修**：点击「✏️ 编辑」按钮自动携带 `?edit=1` 打开目标页面并激活在线精修模式。

## 三、使用方式与快捷键

1. **唤起面板**：
   - 快捷键：在浏览器页面中随时按下 **`Alt+M`**（或在非输入状态下按下 **`M`**）。
   - 顶栏按钮：点击顶栏右侧动作区（主题/字体切换旁）的 📖 书籍巡检图标。
2. **关闭面板**：
   - 按 **`Esc`** 键、点击面板右上角 **✕**、或点击暗色遮罩背景。
3. **刷新扫描**：
   - 点击面板顶部的 🔄 刷新按钮，即时重新读取磁盘文件。
4. **运行时启停**：
   - 点击顶栏右侧的 ⚙ 功能开关面板（`FeatureToggles`），可随时勾选/取消勾选「模块查看与查重」。

## 四、架构与实现

- **配置注册**：`src/config/features.config.mjs` 中的 `inspector` 定义（`cat: 'dev'`, `devOnly: true`, `ui: true`）。
- **扫描核心**：`src/utils/module-inspector/scanner.mjs`（纯 ESM，递归自然排序扫描 MDX，标题归一化、片段提取与查重算法）。
- **服务端插件**：`src/utils/module-inspector/dev-server-plugin.mjs`（Vite connect middleware，提供 `/__inspector__/modules` 与 `/__inspector__/books` 端点）。
- **客户端控制器**：`src/utils/module-inspector/inspector.ts`（状态管理、搜索过滤、分组渲染、SPA 跨页高亮）。
- **服务端壳组件**：`src/components/ModuleInspector.astro`（由 `FooterOverride.astro` 按条件挂载）。
