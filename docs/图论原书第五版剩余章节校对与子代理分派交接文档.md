## 4. 子代理轻量级分派规程 (Subagent Protocol)

为了**避免快速消耗上下文配额、杜绝子代理发散漫游、防止单次输出超限 (65k tokens)**，接手 Agent 必须严格落实以下原则：

### 4.1 核心执行纪律（三要三不要）
1. **要最小化上下文**：给子代理的 Prompt 仅包含目标小节的文件路径和对应页面的 PNG 路径。**绝对不要**把全局规则文件、全书目录或不相干的代码塞给子代理。
2. **要纯净双动词约束**：子代理的合法操作仅有 `read_file`（读 PNG 和读原 MDX）与 `write_file`（覆盖写入精修后的 MDX）。
3. **要单节定额分流**：每个子代理仅负责 1 个小节（对应原书切片通常为 2~8 页）。
4. **不要允许执行命令**：在子代理系统提示词中**显式禁止使用 `run_command`**，严禁子代理自行运行 git、npm 或目录遍历搜索。
5. **不要让大模型处理大体量习题**：若习题超过 30 道（如第 12 章习题共 41 道），主 Agent 应使用 Python 脚本执行确定性正则切分并内嵌提示，禁止让子代理单次全部吐出，防止截断。
6. **不要包裹注解为卡片**：各章“第X章注解.mdx”纯粹用于文献回顾与历史研讨，全章一律使用纯 Markdown，禁止使用 `<Knowledge>`。

### 4.2 子代理系统提示词标准模版 (System Prompt)

创建或派发子代理时，使用如下极简、严谨的 System Prompt：

```markdown
You are an expert mathematical textbook proofreader and typographer.
Your sole job is to proofread and correct a Chinese MDX chapter of Reinhard Diestel's "Graph Theory" against the provided original book scanned page PNGs.

STRICT CONSTRAINTS:
1. ONLY use tools `read_file` (to view assigned page PNGs and the current MDX file) and `write_file` (to save the final corrected MDX).
2. DO NOT run any bash/powershell commands (run_command is strictly forbidden).
3. DO NOT search the workspace or inspect unrelated files.
4. DO NOT invent cards:
   - Only wrap genuine new theorems/definitions in <Knowledge title="...">.
   - Mentions, citations, or historical references to theorems MUST remain plain text.
   - Notes chapters (*_第*章注解.mdx) MUST contain ZERO <Knowledge> cards.
5. NO TRAILING HEADINGS: Never leave the next section's heading at the bottom of the file.
6. FIGURES: Format figures strictly as:
   <figure class="vp-figure">
     <img src="images/xxx.png" alt="图 X.X ..." />

   </figure>
7. MATH: Ensure KaTeX syntax is pristine (inline `$ ... $`, display `$$ ... $$`, tombstone `∎`).
```

## 5. 五大质量红线与防御要点 (The 5 Golden Rules)

| 规则 | 判定标准 | 违规后果与预防手段 |
| :--- | :--- | :--- |
| **红线 1：定理引用防误卡化** | 凡是“定理 9.1.1 的一个应用是…”、“通常归功于 Ramsey(1930)…”等提及性文字，必须保持纯文本。 | 违规会导致右侧大纲（TOC）产生重复混乱的假锚点。<br>👉 **对策**：在 `*注解.mdx` 全篇禁用 `<Knowledge>`；正文二次提及使用纯文本。 |
| **红线 2：小节末尾防残留标题** | MDX 文件末尾严禁出现下一节的标题（如 `9.1` 末尾绝不能有 `## 9.2 Ramsey数`）。 | 违规会导致读者阅读至页尾时看到突兀的大标题与空白。<br>👉 **对策**：文件写入前逆向清空末尾大纲标记。 |
| **红线 3：图注语义严格绑定** | 图片与其图注必须严格绑定为：<br>`<figure class="vp-figure"><img ... /><figcaption>图 X.X ...</figcaption></figure>` | 违规会导致 `<figcaption>` 掉出图框并丧失样式，图注与图片断裂。<br>👉 **对策**：严格使用 `<img>` 标签，禁止在已有 `<figure>` 内部写 Markdown 图片语法 `![]()`。 |
| **红线 4：密集习题切分与内嵌** | 课后题必须独立切分为 `<Exercise title="练习 N[⁺/⁻]">`，且保留原书难易度标记。 | 违规会导致多道题混为一谈，读者自测体验崩溃。<br>👉 **对策**：从书末附录匹配对应章的提示，嵌套为 `<Solution title="提示">...</Solution>`。 |
| **红线 5：KaTeX 公式严谨闭合** | 导数撇号规范为 `$G^{\prime}$`、`$G^{\prime\prime}$`；标号下标规范为 `\tag{($*_{\alpha}$)}`；证明结尾保留 `∎`。 | 违规会导致前端 KaTeX parse error 阻断整页渲染。 |
