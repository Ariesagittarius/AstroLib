# 项目概览

AstroLib 是一个面向大学理工科教材与学术资料的数字化阅读与自测系统。系统以严谨学术排版为核心，遵循“内容即界面（The Content is the Interface）”原则，消除无关的视觉噪声，使数学公式、推导过程与逻辑结构成为阅读的核心。

---

## 核心设计与技术优势

### 1. Material You (Material 3) 学术排版
- **官方组件规范**：全站 UI 深入采用 Google Material Design 3 规范，优先采用官方 `@material/web` 组件（Filter Chips、Outlined Text Field、Filled Tonal 卡片、Switch 双轨开关），杜绝不必要的边框嵌套。
- **动态配色与无压质感**：基于 `@material/material-color-utilities` 提取色彩基调，提供柔和的表面色彩层级（Surface Colors），长时间阅读不疲劳。
- **公式优先排版**：严格对齐思源宋体、思源黑体与 KaTeX 公式基线，针对行内公式与独立块级公式进行间距微调，杜绝公式缩放溢出与排版错位。

### 2. 印刷级 LaTeX 导出
- **解耦式编译架构**：导出引擎独立于 Web 运行时，基于 `Jinwen-XU/homework` 等成熟宏包，将网页教材内容编译为标准 LaTeX 文档。
- **云端与本地双模支持**：支持通过 GitHub Actions 工作流在云端调度 TeXLive 自动编译生成 PDF，或在本地直接导出 `.tex` 源码，无需在个人电脑安装体积庞大的 TeXLive 即可输出学术讲义与试卷。
- **预设版面配置**：内置多种页面版式预设，支持自定义作业头、分栏排版与题号样式。

### 3. 标准离线 EPUB3 导出
- **离线离网阅读**：提供独立打包脚本（`npm run epub`），将整本教材转换为标准 EPUB3 电子书文件。
- **公式矢量化呈现**：公式在编译期预渲染为高清晰度矢量 SVG 或标准化 HTML，在主流移动阅读器（如微信读书、Apple Books、Kindle 及墨水屏设备）上保持稳定渲染。

### 4. 配套习题册
- **结构化真题与习题**：系统整合名校历年期中、期末真题（如《大邮数学集》173 套试卷，2900+ 题），与各章节教材知识点建立映射。
- **双模练习体验**：
  - **章节自测**：在各节末尾通过卡片调出对应知识点的习题。
  - **整卷练习**：在独立面板中调出完整试卷进行模拟测试。
- **交互与推导折叠**：支持即时对错校验、答案与步骤折叠、AI 辅助分步推导以及 LaTeX 试卷导出。

### 5. 跨页引用与知识网络
- **构建期静态下沉**：通过 Rehype 插件在 AST 编译阶段解析定理、定义、例题与公式标签（`\tag{...}`），生成交叉引用索引。
- **零运行时开销**：正文中出现的跨章节引用直接生成轻量跳转徽章，悬浮即可预览目标内容，点击即可定位。
- **知识关系图谱**：基于模块依赖关系提取概念前驱与后继网络，在右侧 Sideload 面板中以图谱形式直观呈现知识结构。

### 6. Agent MCP 工具链融合 AI 问答
- **模型上下文协议（MCP）**：系统遵循 MCP 规范，将教材目录树、正文切片、数学公式、例题和真题库抽象为标准的端侧可调用工具（MCP Tools）。
- **可溯源 RAG 架构**：大语言模型在回答专业数学/物理问题时，必须通过工具调用本地知识片段作为证据，严防凭空编造（幻觉），回答结果附带精确的章节与公式出处跳转链接。
- **端侧 BYOK 隐私优先**：用户在本地配置个人 API Key（支持 Gemini、DeepSeek 与自定义端点），所有交互直连模型服务商，无第三方服务器转存。
