# 《大邮数学集》题库结构化抽取与分章习题集成交接文档

## 1. 项目背景与需求概述

本项目旨在将 `.agents/src/大邮数学集-1.4.2.pdf`（552 页，173 套由北京邮电大学开源团队排版的历年真题试卷）中的全部题目与答案，解析并转化为高可扩展的标准化 JSON 格式题库，并实现与全站教材（首发以《工科数学分析基础》为主）的分章课后真题练习整合，便于学生在完成各章节理论学习后，即时进行名校真题自测与针对性训练。

## 4. JSON 数据库规范与 Schema 定义

题目实体在 `bupt_math_full_database.json` 与 `engineering_analysis_exercises.json` 中统一遵循如下数据结构：

```typescript
interface QuestionItem {
  id: string; // 题目唯一标识符，如 "BUPT-MATH-P001-Q03"
  source: {
    paper_id: number; // 试卷序号 (1..173)
    raw_title: string; // 试卷原始标题
    category: string; // 试卷分类，如 "分析上期中", "分析下期末", "线代期末"
    course_name: string; // 课程名，如 "工科数学分析"
    academic_year: string; // 学年，如 "2025-2026"
    term: number; // 学期 (1 或 2)
    exam_type: "midterm" | "final" | "resit"; // 期中 / 期末 / 补考
    paper_type: "A卷" | "B卷" | "综合"; // 卷别
    page_start: number; // 所在 PDF 起始页
    page_end: number; // 所在 PDF 结束页
  };
  meta: {
    section_type: string; // 大题分类，如 "一、填空题（共 30 分，每小题 5 分）"
    type: "choice" | "blank" | "calc" | "proof" | "comprehensive"; // 题型
    order_in_paper: number; // 试卷内题号 (1..n)
    score?: number; // 分值 (5.0, 12.0 等)
    difficulty: number; // 难度评级 (1:基础, 2:中等, 3:进阶, 4:拔高)
  };
  content: {
    stem: string; // 题干 (标准 LaTeX 公式经 $...$ 包裹)
    options: Array<{ key: string; text: string }>; // 选择题选项 (A, B, C, D)
    sub_questions: Array<{ sub_id: string; stem: string; answer?: string }>; // 大题小问 ((1), (2)...)
  };
  solution: {
    answer: string; // 标准参考答案 (如 "D", "$\frac{6}{5}$", "$\frac{\mathrm{d}y}{\mathrm{d}x}=\frac{1}{t}$")
    hints?: string; // 官方或自研解题思路提示
    steps?: string; // 详细证明或计算步骤
  };
  mapping: {
    engineering_analysis?: {
      volume: "upper" | "lower"; // 上册 / 下册
      chapter: number; // 章号 (1..7)
      chapter_title: string; // 章名 (如 "第1章 极限与连续")
      section: string; // 节号 (如 "1.3")
      section_title: string; // 节名 (如 "函数的极限")
      section_slug: string; // MDX slug (如 "1.3_函数的极限")
      knowledge_points: string[]; // 考察知识点标签列表
      cognitive_level: "remember" | "understand" | "apply" | "analyze"; // 认知层级
    };
    linear_algebra?: { ... };
    probability_statistics?: { ... };
  };
}
```

## 5. 核心算法与高精公式清洗架构

### 5.1 双轨混合重构流水线 (Hybrid SOTA Architecture)
针对 1D 纯文本流丢失 2D 排版几何结构（分子分母拆散、上下标丢失、嵌套根号塌缩）的痛点，构建了高精度视觉模型辅助与本地结构化结合的双轨流水线：

```
PDF 试卷 (552页) ───► PyMuPDF TOC 结构化切分 (0 Token)
                          │
                          ▼
                 150 DPI 高清灰度栅格化 (轻量化传输)
                          │
                          ▼
             Gemini 2.5 Flash 视觉多模态批量解析
        (整卷批处理 + 紧凑 JSON Schema + 自动重试)
                          │
                          ▼
           状态机 JSON 解析器 (自动修复 LaTeX 反斜杠)
                          │
                          ▼
     本地磁盘断点缓存 (src/data/exercises/raw_papers/)
                          │
                          ▼
       知识图谱智能分章对齐 (CurriculumClassifier)
                          │
                          ▼
            MDX / KaTeX 语法自愈与转义保护 (escape_for_mdx)
                          │
                          ▼
   JSON 题库导出 ──► ChapterQuiz 组件 ──► 58 个章节 MDX 页面
```

### 5.2 试卷级批量重构与 Token 极简控制 (`vision_cleaner.py`)
1. **按“整套试卷”而非“单题”调用**：
   - 将整套试卷 2~3 页图像一次性送入 Vision LLM，批量转录整套试卷全部试题与末尾答案，大幅削减握手与 Prompt 冗余。
   - **单卷 Token 消耗仅约 4,000 tokens**（输入 ~1.3k，输出 ~2.7k）。
   - 全量 173 套试卷总计仅消耗 **~0.69M tokens**（不到 1.5 元人民币），在 Google AI Studio 免费每日配额内即可轻松完成。
2. **状态机 LaTeX JSON 健壮解析器 (`parse_latex_json`)**：
   - 解决了大模型输出 LaTeX 公式时未转义反斜杠（如 `\frac`, `\underline`, `\begin`）导致标准 `json.loads` 报 `Invalid \escape` 的业界共性难题。
   - 通过字符级词法状态机精确识别字符串字面量边界，自动安全修复反斜杠，实现 100% 稳定解析。
3. **本地磁盘断点缓存 (Resumable Disk Cache)**：
   - 每次成功解析即存入 `src/data/exercises/raw_papers/paper_{id:03d}.json`。
   - 再次运行时自动跳过已有缓存，支持任意时刻中断并断点续传，**0 重复开销**。

### 5.3 MDX 转义保护与 KaTeX 语法维护 (`formula_reconstructor.py`)
- **公式内部纯净性**：保护 `$ ... $` 与 `$$ ... $$` 内部的标准 LaTeX 语法与大括号，防止误替换。
- **公式外部 JSX 转义**：将非公式区域的裸 `{` 与 `}` 转换为 `&#123;` 与 `&#125;`，确保 Astro JSX 编译器编译零报错。

### 5.4 知识图谱与自动分类对齐 (`curriculum_mapper.py`)
构建了与《工科数学分析基础》36 个小节完全对齐的关键词与强特征加权矩阵：
- 例如识别到 `间断点` / `连续点` 自动优先匹配 `1.5_连续函数`；
- 识别到 `罗尔` / `拉格朗日` / `中值定理` 自动优先匹配 `2.4_微分中值定理及其应用`；
- 识别到 `格林公式` / `高斯公式` / `散度` / `旋度` 自动匹配 `6.8_各种积分的联系及其在场论中的应用`；
- 智能区分《分析上》（第 1-4 章）、《分析下》（第 5-7 章）、《线性代数》与《概率论》。

## 6. 日常运维与常用命令指南

### 6.1 题库重构与清洗命令

```bash
# 1. 试跑前 N 套试卷（例如测试前 5 套）
.venv\Scripts\python scripts/process_bupt_math_archive.py --mode vision --sample 5

# 2. 仅清洗指定分类（例如工科数分期中试卷）
.venv\Scripts\python scripts/process_bupt_math_archive.py --mode vision --category 分析上期中

# 3. 指定试卷 ID 清洗（例如清洗第 1、2、3 套）
.venv\Scripts\python scripts/process_bupt_math_archive.py --mode vision --paper-ids 1,2,3

# 4. 全量清洗全书 173 套试卷（自动读取已有缓存，未缓存部分调用 API）
.venv\Scripts\python scripts/process_bupt_math_archive.py --mode vision

# 5. 强制重新识别某套试卷（忽略本地缓存）
.venv\Scripts\python scripts/process_bupt_math_archive.py --mode vision --paper-ids 1 --force
```

### 6.2 语法与 KaTeX 质量校验
修改或新增 MDX 后必须运行以下校验命令：
```bash
# 1. 校验《工科数学分析》MDX 章节语法与公式
node scripts/scan-mdx.mjs src/content/docs/collections/math/engineering_analysis

# 2. 校验全站 KaTeX 字符规范
npm run check:katex
```

## 7. 章节习题独立交互模块架构（新版）

针对“课后习题不作为扁平并列文章”的要求，已全面升级为**独立题库自测中心**（`ExerciseCenter` / `ExerciseModal`）架构：

1. **去并列化与目录纯净化**：
   - 移除了原作为普通文章并列在左侧边栏的真题精选与答案 MDX 页面；
   - 在各章节（1.1～7.4）末尾内嵌 `<ExerciseTrigger chapter={n} section="..." />` 优雅 SVG 卡片入口，右侧大纲导航栏常驻 `习题 (Alt+E)` 快捷入口。
2. **独立模态/全屏交互窗口 (`ExerciseModal`)**：
   - 沉浸式弹窗与一键全屏切换，支持 `Esc` 退出；
   - **做题自判模式 (Practice)**：单选题即时判分与高亮、填空题自动核对、证明/大题推导折叠与掌握度自评，配套实时正确率统计；
   - **题库检索模式 (Search)**：按小节、题型、年份/来源多维过滤，支持题干、考点与 LaTeX 毫秒级模糊检索。
3. **高性能按章懒加载 (0ms SSR 负担)**：
   - 数据静态切片为 `public/data/exercises/engineering_analysis/ch{1..7}.json`（单章仅数十 KB），按需异步 Fetch + 内存 Map 缓存；
   - 局部按需 KaTeX 渲染（`renderMathInElement`），保障 60fps 流畅操作。
4. **AI 深度题解联动 (`aiAsk`)**：
   - 题目卡片提供「问 AI 题解」SVG 按钮；
   - 点击自动组装专业数学教研 Prompt（包含考点剖析、规范推导、易错警示要求），并分发 `aiask:query` 激活现有 `AIAsk` 模块流式公式输出。
5. **设计风格规范**：
   - 遵循 VitePress 优雅学术风，纯 SVG 矢量图标，严格禁用 Emoji，自适应明暗主题。
