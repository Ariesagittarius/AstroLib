## 2. 核心架构决策与排版设计契约

### 2.1 分块与防接缝丢失策略（Section-based Chunking with Overlap）
- **杜绝固定 2~3 页盲切**：不采用机械切片分块，全面采用**按自然小节（Section-based）**推进；
- **短小节（$\le 5$ 物理页）**：一次性使用 `view_file` 统揽整节（如 3~4 张图），直接输出完整节的 MDX，从根本上消灭跨页缝隙与推导截断；
- **长小节（$> 5$ 物理页）**：采用 **1 页重叠滑动窗口**（如第一批看 P.136~140，第二批看 P.140~144），由 Agent 确保前一批末尾的公式/定理在后一批无缝衔接。

### 2.2 语义卡片极端减法（4 大学术核心卡片）
由于《通信原理（第5版）》为正规单栏排版，无复杂的宽边栏批注，全面剔除 `<SideNote>`, `<Variant>`, `<Guide>`, `<Method>` 等繁琐卡片，统一收敛为 **4 大核心学术容器**：
1. **核心概念 / 定理 / 准则 / 模型**：统一使用 `<Knowledge title="...">`；
2. **典型例题**：统一使用 `<Example title="...">`（题干超过 60 字时，仅在 title 中保留题号如 `title="例 2.3"`，详细题设放入卡片第一段 Markdown，严防全局加粗溢出）；
3. **解答与推导**：统一使用 `<Solution title="解">` 或 `<Solution title="证明">`；
4. **章尾互动自测触发器**：统一在小节末尾挂载 `<ExerciseTrigger chapter={X} section="X.Y" title="..." />`；
5. **其余内容**：背景介绍、物理意义、工程阐述、列表等一律使用干净利落的纯 Markdown 正文段落与无序列表，呈现纯正学术呼吸感。

### 2.4 100% 工业级 KaTeX 纯净度规范
- **变量与信号表示**：时域连续信号 $s(t)$、复包络 $\tilde{s}(t)$、等效低通冲激响应 $h_b(t)$、频域变换 $S(f)$、功率谱密度 $P_s(f)$ 全部置于行内数学模式 `$...$`；
- **粗斜体矩阵与向量**：生成矩阵 $\boldsymbol{G}$、监督矩阵 $\boldsymbol{H}$、接收矢量 $\boldsymbol{r}$ 严格采用 `\boldsymbol{...}`；
- **严防多行环境嵌套 `\tag`**：在 `aligned`、`cases` 或矩阵内严禁使用 `\tag`，多行编号统一采用对齐符与带括号文本（`& (5.1) \\ & (5.2)`）；
- **剔除带圈字符**：禁止在公式中出现 Unicode 带圈数字 `①, ②`，统一用标准 ASCII `(1), (2)`。
